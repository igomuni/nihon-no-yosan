# 0001 リポジトリの役割と構成

日付: 2026-10-22。状態: 決定。

## 決めたこと

- **役割:** 日本の国の予算を、概算要求・当初予算・補正予算・決算でつなぎ、行政事業レビュー（RS）の事業ともつなぐ。データ基盤と画面を持つ。
- **公開:** 公開リポジトリ。コードは MIT。
- **構成:** npm workspaces。`packages/core`（純粋な関数と型）・`packages/pipeline`（データを作る）・`apps/web`（画面）。依存の向きは `web → core ← pipeline` で、web は pipeline を import しない。
- **他のリポジトリへの引き継ぎ:** rs-vis などに機能を入れるときは、コードを複製しない。このリポジトリのガイドを指示書にして作り直す。そのため、ガイドは「これだけで作り直せること」を基準に書く（`docs/guides/documentation.md`）。

## 理由

- 前のリポジトリ（[marumie-rssystem](https://github.com/igomuni/marumie-rssystem)）は、研究の記録（正解データ・事前登録・PoC）と、3 系統の財務省のデータ、約 600 MiB の履歴を抱えていた。新しい機能を、本番の処理だけで組み直すために分けた。
- core を共有すると、データを作る側と画面の側で、鍵・表記の揃え方・検算を複製せずに済む。前のリポジトリでは、層を分ける規則のために複製が生じていた。

## 選ばなかった案

- **データのリポジトリと画面のリポジトリを分ける:** core を両方で使うため、1 つのリポジトリの中で分ける方が単純。
- **前のリポジトリの中で整理する:** 研究の記録と履歴の重さが残る。

## 持ち込まないもの

研究の記録、前のリポジトリの古い 2 系統の財務省データ（V1・V2）、RS 中心の既存の画面（/sankey-svg など）。RS の画面は、予算とつないだ形で作り直す。
