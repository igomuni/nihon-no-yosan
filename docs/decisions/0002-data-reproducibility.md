# 0002 データの正・基準・再現性・公開

日付: 2026-10-22。状態: 決定。仕様は `docs/guides/data.md`。

## 決めたこと

- **最終的な正は公式の原本。** 原本の形の CSV は、正規化と構築の基準データ（起点）であって、正そのものではない。
- **原本は git に入れない。** URL と SHA-256 を manifest に書く。原本そのものは再配布しない。
- **基準データと構築データは、版つきのデータセットにする。** git には画面用の小さな JSON だけを入れる。
- **初版の再現性の境界:** 凍結した基準データからの再生成まで。原本の PDF からの再抽出は次の段。
- **公開の関門:** 各出典の利用条件と出典表記を確かめるまで、データセットを公開しない。

## 理由

- 原本（PDF・zip）は GB 級で、git に向かない。基準データも 100 MB 級ある。
- 概算要求書の PDF からの抽出は、前のリポジトリで多くの研究を経た処理で、移すのに時間がかかる。次に必要になるのは FY2028 の概算要求（2027 年 8〜9 月）なので、それまでに移せばよい。
- 公開リポジトリなので、データの再配布の条件を先に確かめる。
