# 0005 国会・裁判所の概算要求書の plain text も入れる

日付: 2026-10-23。状態: 決定。0004 の「文章（説明・備考の積算内訳など）は入れない」を置き換える。ほかは 0004 のまま。

## 決めたこと

- 衆議院・参議院・裁判所・裁判官訴追委員会・裁判官弾劾裁判所の概算要求書の plain text（PDF から `pdftotext -layout` で取った全文）も、ほかの出典と同じくデータセットに入れ、公開する。
- 原本の PDF と画像は入れない（0004 のまま）。名前・コード・額・頁の CSV も 0004 のまま。
- 出典の書き方は、ほかの出典と同じ（`docs/guides/data.md`）。

## 理由

- 前のリポジトリの build は plain text を読む（事項要求の検知、不一致の分類）。入力の契約を機関ごとに分けず、全機関で同じにする方が単純で、作り直しの手順も 1 通りになる。
- 中身を数えた。5 機関の FY2023〜FY2027 の plain text は 25 ファイル、3.9 MB、919 頁、約 3.0 万行。大半は科目名・金額・積算内訳の表。文章らしい行（20 字以上で句読点があり、数字が 4 割未満）は約 451 行で、表の行も含むので上限。例は「（注）当該経費に係る（目）庁費の一部については、共通経費に計上している。」のような短い注。

## 前提と危うさ

- 各サイトの規約は、著作権法で認められる利用に限り、無断の改変を認めていない（`docs/guides/data.md`）。この決定は、全文でも、表の行と短い注が大半で、創作的な表現と言える部分が小さいという解釈に立つ。法律の専門家には確かめていない。
- 0004 より危うさが大きい。0004 は事実だけの表だったが、これは文章を含む。文章らしい行は、少ないが、ゼロではない。
- 機関から求めがあれば、その機関の分（CSV も plain text も）をデータセットから外す。
- 公開は、利用条件が未確認の機関を確かめてから（`docs/guides/data.md`）。

## 選ばなかった案

- **PDL1.0 の出典の分だけ入れる:** 規約に最も沿うが、入力の契約が機関で分かれる。作り直せないのは、国会・裁判所の分で、事項要求の検知に当たる 1 件（裁判所）とその書の不一致の分類だけ。
- **plain text は手元だけに持つ:** 事項要求の検知などが、データセットから作り直せなくなる。
