# 0004 国会・裁判所の概算要求書から作ったデータを入れる

日付: 2026-10-22。状態: 決定。

## 決めたこと

- 衆議院・参議院・裁判所・裁判官訴追委員会・裁判官弾劾裁判所の概算要求書から作った基準データ（原本の形の CSV）を、ほかの出典と同じくデータセットに入れ、公開する。
- 根拠は、入れるものが事実のデータ（項・事項・目の名前、コード、額、頁）で、著作物に当たらないという判断。
- 入れるのは、名前・コード・額・頁の表だけ。原本の PDF、文章（説明・備考の積算内訳など）、画像は入れない。
- 出典は、ほかの出典と同じ形で書く（例: `出典：衆議院「令和8年度歳出概算要求書」（PDF の URL）を加工して作成`）。

## 理由

- 予算額と、項・事項・目の名前は、国の予算という事実を表すデータで、表現の創作性がない。公共データ利用規約（第1.0版）も「数値データ、簡単な表・グラフ等は著作権による保護の対象ではありません」としている。
- 2026-10-22 の時点で、これらの書から作った CSV（FY2023〜FY2027 の 5 機関。総表・明細表・目次・表紙が各 25 ファイル）の行は、すべて名前・コード・額・頁で、文章を含まない。
- 国会・裁判所を除くと、国の予算の一部が欠け、所管の合計が合わなくなる。

## 前提と危うさ

- 各サイトの規約は、著作権法で認められる利用に限り、無断の改変を認めていない（`docs/guides/data.md`）。この決定は、入れるものがそもそも著作物でないという解釈に立つ。法律の専門家には確かめていない。
- 機関から求めがあれば、その機関の分をデータセットから外す。

## 選ばなかった案

- **公開するデータセットから外す:** 規約に最も沿うが、国の予算の全体が欠ける。
- **各機関に問い合わせ、許可を得てから入れる:** 確実だが、返事を待つ間は進められない。
