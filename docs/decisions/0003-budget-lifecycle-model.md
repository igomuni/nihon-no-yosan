# 0003 予算の一生の表の形

日付: 2026-10-22。状態: 方針は決定、データの契約は未確定（実装の前に `docs/guides/` で確定する）。

## 決めたこと

- **項（識別）と、項に起きた出来事（イベント）を分ける。** 出来事は、概算要求・政府案・成立・補正・決算の各列。補正の号・版（例: FY2025 の提出時と成立後）・起きた順を持つ。
- **額は、正規化した円と、原本の値・単位を両方持つ。** 原本の単位は、当初・補正が千円、決算が円。
- **値の状態を分ける:** 原本の値 / 導出した値 / 未解決。空欄と 0 を区別し、計算で値を補わない。補正の累計の値（成立予算額・改予算額）は原本の値として持ち、号ごとの差額は導出した値にする。
- **年度をまたぐ項の対応は、別の表にする。** 根拠（同じ鍵・名前の対応表・前年度予算額の一致など）の種類と、状態 `RESOLVED` / `AMBIGUOUS` / `UNRESOLVED` を持つ。額の一致は候補を支える証拠であって、同じ項の保証ではない。
- **図の意味を分ける:** 要求から決算までの額の変化はブリッジ（滝グラフ）。サンキー（帯の幅が保存される図）にするのは、決算の現額の構成と配分（歳出予算額・繰越等 → 現額 → 支出済・翌年度繰越・不用）だけ。
- **最初の対象は FY2023・FY2024**（概算要求から決算までそろう年度）。

## 理由

- 同じ年度・同じ項に補正が複数あり、累計の値もあるので、「段階」の列 1 つでは表せない。
- 予算書の前年度予算額は、多くの項で前年度の補正後の額と一致するが、FY2026 で当初とも補正後とも合わない項が 129 あった（原因は未確認）。
- 要求 → 政府案は査定による増減で、お金の移動ではない。当初 → 補正 → 改予算額は累計の変化で、減額もある。これらをサンキーにすると、帯の幅が保存されるように見えて誤解を招く。
