# 概算要求の年度推移の画面（`#/trend`）

項の年度推移（`docs/guides/trend.md`）と、その事項・目（`trend-detail.md`）、事項要求の候補（`jikou-youkyu.md`）を並べて見る画面。実装は `apps/web/src/trend/`、絞り込み・並べ替え・データの合流は `packages/core/src/trend-view.ts`（純粋な関数。テストあり）、金額の表示は `packages/core/src/format.ts`。

```bash
npm run build:data   # 画面が読む JSON を apps/web/public/data/ に作る
npm run dev          # http://localhost:5173/
```

## データ

ブラウザが静的ファイルを直接読む（`apps/web/src/data.ts`）。`trend/kou.json.gz`（キー単位の項、元の PDF の URL）で一覧を出す。`trend/jikou.json.gz` は別に読んで年度の値に合流する（`mergeJikou`。読めなくても一覧は出す）。`trend/detail.json.gz` は詳細の「事項」「目」のタブ用で、一覧の表示を待たずに後から読み、事項・目の数を年度の値に合流する（`mergeDetailCounts`）。MOF の予算書との突合には依存しない。名称が変わった項は別の行（新規・消滅）になる（`moved` でつないだものを除く）。

## 画面

左がフィルタ、中が選択年度の一覧、右が選んだ項の全年度分の詳細。3 つのペインの境のつまみで、フィルタと詳細の幅を変えられる（画面幅 xl 以上）。

- **金額:** 千円の値を、円・万円・億円・兆円に自動で切り替える（`formatBudgetShort`）。増減・増減率は、その年度の要求額 − 前年度予算額（その年度の要求書が載せる値どうし）。
- **一覧の 1 行 = 項。** 複数の府省の要求書に載る項（複数所管）も 1 行。同額（同じ要求書を各府省が載せている）と、東日本大震災復興の持ち分（各省の書と復興庁の合計の書）の 2 種類で、金額はその年度の値（書ごとに額が違うときは最も大きい額＝合計書）。一覧の合計は二重に数えない。列は 所管 → 会計（一般会計 / ○○特別会計）→ 組織（特別会計は勘定）→ 項名 → 出現パターン → 前年度予算額 → 要求額 → 増減 → 増減率 → 事項数 → 目数。列の幅はドラッグで変えられ、見出しで並べ替える。上位 600 件まで出す（選んだ項が外にあれば、そこまで出す）。
- **所管:** その年度に載っている要求書の公開元の府省（PDF のドメイン由来。`publisherOf`）。要求書が引けないときだけ表紙の所管名。複数所管の行は「N所管」とし、府省名はツールチップと詳細に出す。一般会計の内閣府の外局（消費者庁、金融庁など）も、それぞれの書の府省として別に数える。
- **出現パターン:** 選択年度と前年度の比較。新規（前年度の要求書に無い）・継続・消滅（前年度にあり、この年度に無い）。最初の年度は判定しない。消滅を選ぶと、前年度の行を出す。
- **バッジ:** 事項要求（項の中、組織の行）、繰入、紐づけ候補、移管・改称、会計新設、コード変更、画像頁、PDF頁なし、持ち分、額不一致、複数書。ツールチップに理由を出す。

## フィルタ

所管（府省ごとと「複数所管」。府省を選ぶと、その府省が載せている複数所管の項も出る）、会計、組織／勘定と項名の検索（部分一致。`.*` で正規表現。大文字小文字は区別しない。正規表現は 128 文字まで。不正なら何も一致しない）、出現パターン、要求額の前年度予算額比（±10%・±50%）、データの状態。データの状態は、複数書、額不一致、持ち分、繰入、所管コードの変更、会計・勘定の新設、移管・改称、画像頁、PDF頁なし、事項要求。件数は選択年度のもの。

- **複数書:** 同じ府省の複数の要求書に載る項だけ（例: FY2023 金融庁の分冊）。複数所管の項は所管の列（N所管）で分かるので含めない。
- **持ち分:** 複数の府省の書に載り、書によって額が違い、最も大きい額の書がほかの書の和以上（東日本大震災復興）。額不一致は、持ち分でない書によって額が違うもの。

## 詳細

タブ「推移 / 事項 / 目」。ラベルに、選択年度の事項・目の数（目は事項をまたいで目名 + 目別で数える）。

- **推移:** 要求額の棒グラフ（前年度予算額の線つき）、年度の表（前年度予算額・要求額・増減・査定差・元の要求書と頁）、複数の書に載る年度の要求書の表、紐づけの候補、注。年度のクリックで一覧の年度が切り替わる。査定差 = 翌年度の「前年度予算額」− その年度の要求額（負なら要求より予算が少ない）。PDF のリンクは `#page=<PDF頁>`。
- **事項:** 行 = 事項名、列 = 年度の要求額（総表の値）の表と「事項の計」（項の要求額と合わなければ色付き）。選択年度の検算が一致でない事項に状態を添える。下に、選択年度の事項ごとの目。
- **目:** 行 = 目（目名 + 目別。事項をまたいで足す）、列 = 年度の要求額の表と「目の計」。下に、選択年度の目の集計（2 つ以上の事項にまたがる目は事項ごとの内訳）。細分の合計を使った目に「※」。
- 移管・改称でつないだ行は、前の年度のキー（名前・所属）が違うので、事項・目の内訳を引けない年度がある。

## 保存

年度、詳細のタブ、ペインと列の幅は、ブラウザの localStorage（キーは `trend:*`）に保存する。保存できなくても動く。フィルタと並べ替え、選んだ項は保存しない。
