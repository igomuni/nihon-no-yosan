# 概算要求書の備考欄の記号

概算要求書の明細表の備考欄に、「環 A17」「沖 K00」のような、漢字 1 字と英字 1 字と数字 2 桁の記号が付く。予算書（当初予算・補正）の CSV には出ない。この文書は、記号の洗い出しと、意味の裏取りの結果を残す。画面とデータには、まだ取り込んでいない。

## 要約

- 記号は、府省をまたぐ取りまとめの区分を表すと見られる（推測）。要求書のどこにも凡例が無く、記号の定義を書いた公表資料も見つかっていない。
- **「環 A」は、環境省が取りまとめる環境保全経費の施策体系の区分と見られる。** 付いている行の内容、年度ごとの区分の変遷、公表された分野別の金額と合う（下の「裏取り」）。ただし、記号と分野の対応を書いた資料は未確認。
- 「科 R」「沖 K」「宙 M」「海 L」「青 H」は、別の取りまとめ（科学技術関係予算、沖縄関係経費、宇宙関係予算、海洋関連予算、青少年関係予算）の区分と推測する。付いた行の名前は分野と合うが、金額は公表と合わない（記号が付く範囲が狭い）。定義は未確認。

## 記号の洗い出し

### 場所と形

- 原本: 概算要求書の PDF（`data/dataset/reference-v0/budget-request/{年度}/plain-text/*.txt`）。明細表の「備考」の列。
- 形: `{漢字 1 字} {英字 1 字}{数字 2 桁}`。記号どうしの間は空白。1 つの行に複数付くことがある（例: `環 A14 環 A15`、`環 A11 科 R27`）。
- 付く行: 目（`95016‑2305‑16‑7774` のような、組織・項・目の番号つきの行）と、細事項（項・事項の下の 3 桁コードの行）。細事項の行に付いたときは、その下の目の行に記号が無いことがある（目は細事項の記号を引き継ぐものとして読める）。
- 他の府省の行にも付く。例: FY2027 の「環 A17」は、環境省 210、経済産業省 94、内閣府 84、文部科学省 76 行。記号は、行を載せた府省ではなく、取りまとめの区分に付く。
- 用紙サイズ（`A4`）や印刷の文字と取り違えないこと。上の形に当てはまっても、頭の字が `価` `刷` `物` `日` のものは記号ではない（FY2023〜FY2026 に少数）。

- 対応の根拠は、付いた行の内容と、年度ごとの区分の変遷。対応を書いた資料は未確認。

### 金額での照合

要求書の目の行（前年度予算額、要求額、増減）から、記号が **1 つだけ** の行の要求額を足し（千円 → 億円）、公表された概算要求の分野別の額と比べた。

足し方:

1. 目の行の要求額（2 番目の数）を取る。記号は、その行にあればそれ、無ければ直前の細事項の行のもの。
2. **同じ書を複数の府省が載せているので、重複を除く。** エネルギー対策特別会計などの書は、環境省・経済産業省・文部科学省・内閣府が同じ内容を載せる。目の番号、前年度予算額、要求額、記号が同じ行は、書ごとに数え、書の間の最大を取る（除かずに足すと、FY2026 の A11 が 28,917 億円、A18 が 6,618 億円と、約 2 倍になる）。
3. 記号が複数付く行は、配分が分からないので、別に集計する。

### 金額が合わない原因

環境省の公表資料（令和8年度の概算要求。施策体系別・府省別の総括表）の注と、要求書の行を突き合わせた。

- **複数の区分に該当する要求は、公表では「主要区分」で集計される**（総括表の注）。記号が複数付いた行は、行全体が環境保全経費ではなく、環境に関わる部分だけが数えられていると見られる。要求書の行には、その部分の額は載っていない。
- 環を含む複数記号の行（重複除去後、FY2026 で 13,052 億円）の **71% が防衛省**（FY2024 以降は 68〜78%）。防衛省の行は、試験研究費・施設整備費・営舎費・諸器材購入費のような大きな目に、「環 A11 環 A12 環 A13」「環 A11 宙 M00」など、複数の記号を付けている。公表の防衛省の環境保全経費は 927 億円（92,679 百万円）で、防衛省の複数記号の行の約 10%。つまり、記号は目の該当を示し、環境保全経費の額は目の一部と推測する。
- **単独の記号の行は、ほぼ全額が数えられているように見える。** 行に自分で記号が付いた単独の行の合計は 24,208 億円で、公表の総額 24,933 億円の 0.97。細事項から記号を引き継いだ行（1,255 億円）まで入れると 25,462 億円（1.02）。ただし、単独の行でも一部だけが数えられている可能性は除けない。
- 総括表の注では、復興庁の列は東日本大震災復興特別会計の予算で、一部は事業実施府省に計上されている。要求書でも復興特別会計の書を複数の府省が載せるので、府省別の照合は、書の持ち主の整理が要る（未了）。
- 分野ごとの比は、重複除去後の単独の行（自分の記号が付いた行）で、A11 が 15,337 億円（公表 14,173 の 1.08）、A13 が 3,976（3,714 の 1.07）、A14 が 826（805 の 1.03）、A16 が 1,682（2,010 の 0.84）、A15 が 18（47 の 0.38）、A17 が 905（1,688 の 0.54）、A18 が 1,463（2,496 の 0.59）。A15・A17・A18 の差は、細事項から記号を引き継ぐ行、複数記号の行、復興特別会計の計上先の違いが候補だが、未確認。

### 分かったことと、分からないこと

- 記号と分野の対応は、行の内容、金額の桁と傾向（A11 の FY2025 の一致、FY2026 の単独の行の合計と総額の一致）で裏づけられる。
- **記号が付いた行の額は、環境保全経費の額と同じではない。** 複数の記号が付いた行は、目の一部だけが数えられているとみられる。環境保全経費の金額を、要求書だけから再現することは、今はできない。
- 分野ごとの差のうち、A15・A17・A18 の原因は未確認。
- FY2027 の公表値は、未確認（2026-10 時点で見つかっていない）。FY2024 の概算要求の総額も、見つかっていない。
- 「科」「沖」「宙」「海」「青」は、下の節。

## 使い道

今は決めていない。記号は予算書に出ないので、取り込むなら概算要求側の情報として、事項（目）に記号の一覧を持たせる形が考えられる。ただし、記号を取り込んでも、環境保全経費や科学技術関係予算などの金額は再現できない（上の「金額が合わない原因」と、この節）。区分の付け方（どの目に、どの区分の記号が付くか）として使う。
