# データの置き場と再現性

## 段

| 段 | 中身 | 置き場 |
|---|---|---|
| 原本 | 概算要求書の PDF、予算書・決算書の CSV（zip）・XML、行政事業レビューの CSV | 各自の `data/download/`（git に入れない）。URL と SHA-256 を manifest に書く |
| 基準データ | 原本の形の CSV（原本の列・行のまま。足し算・補完をしない） | 版つきのデータセット（予定） |
| 構築データ | 予算の一生の表・突合・年度推移など | 版つきのデータセット（予定） |
| 画面用 | 画面が読む JSON（gz） | git |

## 正と基準

- **最終的な正は公式の原本。** 基準データの値に疑いがあれば、原本で確かめる。
- **基準データは、正規化と構築の起点。** 構築データは、基準データから決まった手順で再生成でき、出力の SHA-256 が一致することを確かめる。

## 再現性の境界

- 初版で保証するのは、凍結した基準データ（データセットの初版）からの再生成まで。
- 原本からの再抽出（特に概算要求書の PDF からの CSV の作成）は、抽出の処理を移す次の段の対象。

## 公開の関門

データセットは、各出典（行政事業レビューシステム、財務省、各府省、国会・裁判所）の利用条件と出典表記を確かめるまで公開しない（下の「出典の利用条件」）。原本そのもの（PDF・zip）は再配布しない。

## 出典の利用条件（2026-10-22 に確認）

各サイトの利用規約・著作権のページで確かめた。規約は変わることがあるので、公開の前に確かめ直す。

| 出典 | 条件 | 加工したものの再配布 |
|---|---|---|
| 内閣府・内閣官房（行政改革推進本部事務局を含む）・財務省・総務省・文部科学省・厚生労働省・農林水産省・国土交通省・環境省・法務省・金融庁・消費者庁・こども家庭庁・警察庁・個人情報保護委員会・人事院・内閣法制局・デジタル庁・会計検査院・国立国会図書館 | [公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)（PDL1.0。CC BY 4.0 と互換） | できる。出典と、加工したこと・加工した者を書く。加工したものを、国が作った未加工の情報のように見せない |
| 衆議院・参議院・裁判所・裁判官訴追委員会 | 著作権法で認められる利用（私的使用・引用など）に限り、出所を明示して転載・複製できる。無断の改変はできない | 規約の上では認められていない。名前・コード・額・頁の表（0004）と、plain text（0005）は、著作物でない、または創作的な部分が小さいと判断して入れる |

- PDL1.0 は「数値データ、簡単な表・グラフ等は著作権による保護の対象ではありません」としている。衆議院・参議院・裁判所・裁判官訴追委員会・裁判官弾劾裁判所の書から作った表は、この解釈で入れる（0004。plain text は文章を含むので、0005 で危うさを書いた）。法律の専門家には確かめていない。
- 経済産業省・外務省・防衛省・宮内庁・復興庁・公正取引委員会・カジノ管理委員会は、検索結果の説明で PDL1.0 と出たが、ページを直接は読めていない（アクセスが拒否された）。未確認。
- 裁判官弾劾裁判所は、利用条件のページを見つけられていない。未確認。
- 行政事業レビュー見える化サイト（`rssystem.go.jp`）自体の利用規約のページは見つけられていない。運営する内閣官房 行政改革推進本部事務局のサイトは PDL1.0 に準拠。

**出典表記の例（PDL1.0）:** `出典：財務省「令和8年度予算書」（ページの URL）を加工して作成`。
