# 概算要求の年度推移（項の粒度, FY2023〜FY2027）

概算要求の項を、年度をまたいで並べる。出力は CSV（`kou.csv`）、件数の記録（`summary.json`）、画面用の JSON（`kou.json.gz`）。予算書との突合は参考情報で、キーにも出力の有無にも使わない。実装は `packages/pipeline/src/build/trend.ts`、動かすのは `trend-cli.ts`、画面用の型は `packages/core/src/budget-request-trend.ts`。画面の仕様は、画面を移すとき（移行の 5）に別のガイドで書く。

```bash
node packages/pipeline/src/build/trend-cli.ts data/dataset/reference-v0 <出力ディレクトリ>   # kou.csv、summary.json、kou.json.gz
```

項の下の事項・目の年度推移は、別の build（`docs/guides/trend-detail.md`）。

## 入力

- 各年度の突合の出力（`docs/guides/match.md`）: `request-kou.csv`（概算要求の木だけから決めた項の所属と金額）と、`m1-kou.csv`（予算書との突合の状態。参考）。年度と予算書の版の対応は、2023→2023、2024→2024、2025→2025（成立後）、2026→2026。
- FY2027 は予算書の令和9年度版が無い。直近の版（2026）を辞書にして突合を動かし、`request-kou.csv` だけを使う（他の出力は、令和8年度の予算書を辞書にした参考にならない値）。`MOF突合(参考)` は空。
- 基準データ: `budget-request/{年度}/cover/sources/*.csv`（表紙の所管コード）、`detail-table/sources/*.csv`（頁と繰入）、`pdf-corpus-freeze.json`（元の PDF の URL）、`plain-text/*.txt`（頁の推定）。

## 列（`kou.csv`。1 行 = 年度 × 項 × 要求書）

| 列 | 内容 |
|---|---|
| `年度` | 概算要求の年度（西暦） |
| `会計区分` | 一般 / 特別 |
| `所管コード` | 表紙の見出しのコード（例: `19` 内閣府、`9905` エネルギー対策特別会計） |
| `所管` | 一般会計の所管名。特別会計は空 |
| `特別会計` `勘定` | 特別会計の名称と勘定（一般会計は空） |
| `組織` `組織の出所` | 組織名と、その出所（`目次` / `総表` / `表紙括弧` / `他の書` / `なし`）。目次から漏れ、総表から補った項（`階層` = `toc_total`）の組織は、目次で直前の項のもので、`目次` |
| `項名` `項コード` | 項の名称（空白を除く）とコード（組織内の連番で、キーにしない） |
| `前年度予算額_千円` `要求額_千円` `増減_千円` | 総表の値。増減は要求額 − 前年度予算額（総表の値ではなく、差を計算）。空欄は空 |
| `要求書` `頁` | 項がある書（slug）と、目次の頁（紙面の印字。`4復興特` のような接頭辞・接尾辞つきもある） |
| `PDF頁` `PDFの要求書` `PDF頁の根拠` `画像頁` | PDF の通し頁と、その頁がある書、頁の根拠（`項` / `頁ラベル` / `推定`）、推定した頁に文字層が無ければ 1 |
| `階層` | 木の作り方（`toc` / `toc_total` / `position` / `position_detail`。`docs/guides/budget-request-tree.md`） |
| `複数書` | 同じキーが同じ年度に複数の要求書にあれば 1（どの行にも付く。複数所管の項も含む） |
| `金額不一致` | `複数書` のうち、要求額か前年度の額が行によって違えば 1 |
| `繰入先` | 項の下の目の名前に「繰入」を含むときの繰入先（目名、「、」区切り） |
| `MOF突合(参考)` | `m1-kou.csv` の `status`（FY2027 は空） |

## キー（年度をまたぐ）

`会計区分 + 所管名（一般会計のみ。特別会計は特別会計名）+ 勘定 + 組織 + 項名`。

- 表紙の所管コードはキーにしない（年金特会 9207 → 2507 のようにコードだけ変わる）。コードは列と画面用 JSON に年度ごとに残す。
- 項コードは組織内の連番で、キーにならない。ただし、同じ要求書の中で同名の別の項（例: 厚生労働調査研究等推進費の 087 / 405）が同じキーになるときは、そのキーを**全年度で**項コードつきの別の行にする（画面用 JSON の `kou`）。年度をまたぐ紐づけを保つため。
- 名称の変更・統廃合の紐づけは、下の「項のつなぎ」。

## 規則

- **組織:** 目次があれば目次の見出し。目次を持たない書は、総表で「組織計」（`TOTAL`）の後ろ（表の始め）にある `CODE3` の行のうち、次の行も `CODE3` のものを組織の見出しとする（項には明細が続く）。それでも決まらない行は、表紙の括弧内の組織で補う。組織が引けなかった特別会計の行は、同じ年度・所管コード・特別会計・勘定・項名で他の書が示す組織が 1 つに決まるときに、それで補う（`他の書`）。
- **会計・所管・特別会計名が明細表の `CONTEXT` 行から決まらない行**は、表紙の見出しで補う（コード 2 桁は一般会計の所管、4 桁は特別会計）。表紙の頁が無い書（総表・明細表から始まる抜粋版）は、所管コード・組織を明細表の先頭の `CONTEXT` 行の見出しから補う。
- **複数の府省の要求書に載る特別会計の項は按分しない。** 同じ特別会計の項が複数の府省の書に載り、額が同じ（総額が各書に載る）。CSV では書ごとに行を残し、`複数書` を付ける。所管をまたいで合計すると二重になる。画面用 JSON では同じキーを 1 つにまとめる。
- **例外: 東日本大震災復興特別会計。** 各書が自分の取り分だけを載せ、復興庁の書が合計を載せる。同じキーで額が違うとき、画面用 JSON は**最も大きい額の書（合計書）**の額を採り（同額なら前年度予算額の大きい方）、各書の `[前年度予算額, 要求額]` を `srcAmt` に残す。
- **PDF の頁:** 同じ書（分冊を含む。書の同定は slug から日付と末尾の連番を除いたもの。`e1` / `e2` のような英字つきの連番は別の書）の明細表の項（`CODE3`）の行を、項コード + 項名（複数に当たるときは組織）で探し、その行の `source_page` をそのまま使う。項が複数の PDF にまたがる分冊は、各 PDF の項の要求額の合計が項の要求額に一致すれば、最初の PDF の最初の頁。決まらない行は、目次の印字頁を明細表の各行の `頁` ラベルに引き当てる。分冊の書は、明細表を持つ PDF が `PDFの要求書`。引けなければ、同じ PDF の印字頁と PDF の頁の差が前後で同じとき（目次の頁の前後 8 頁以内）に推定する（`推定`）。後ろに頁ラベルが無い（以降が画像の頁の）ときは、直前の 2 つの頁ラベルで差が同じとき。推定した頁が plain text で空なら画像の頁（`画像頁` = 1）。明細表の CSV が無い書は、plain text の明細表の表題の頁から先の各頁の先頭行にある印字頁から頁ラベルを作る。
- 検算（要求額 − 前年度 = 増減）は総表の値では行わない。増減は差を計算した値。単位は千円。金額が無い行は空。

## 項のつなぎ（画面用 JSON）

前年度に無い項（新規）と、その年度に無い項（消滅）で、次をすべて満たすものを対応づける。

- 会計区分が同じ。
- 項名が同じか、ほぼ同じ（編集距離 2 以内、6 文字以上）。
- 新規側の前年度予算額が、消滅側の要求額の ±30% 以内（どちらも 0 超）。
- 同名に近い候補が 1 対 1 に決まる。

そのうち、移管元が特定できる次のどちらかは、1 つの行につなぐ（`moved`、年度推移が続く）。両方の項に同じ年度の値があるときはつながない。

- **改称:** 所管（特別会計名）と勘定が同じで、組織か項名だけが変わった。
- **移管:** 移管先の特別会計 + 勘定が、その年度に新設された（前年度に無い）。移管元は消滅側の項。

それ以外の対応は、つながず候補のまま（`from` / `to`）。

**データの状態**（年度ごとの値に付く）: `codeChanged`（所管コードが前の年度から変わった。つないだ項は除く）、`newAcct`（特別会計 + 勘定がその年度に初出。基準データに前年度の書が無いだけでも立つ）、`moved`、`mismatch`（同じキーで額が書によって違う）。

## 画面用 JSON（`kou.json.gz`）

型は `BudgetRequestTrendData`（`packages/core/src/budget-request-trend.ts`）。キー単位に束ね、元の PDF の URL の表（`urls`）を持つ。`gzip` は level 9、mtime 0（同じ中身なら同じバイト列）。年度ごとの値の `src` は `[urls の添字, 目次の頁, PDF の通し頁, 頁の状態]`（頁の状態: `e` = 推定、`i` = 推定した頁が画像、空 = 明細表から引けた）。`jikou`・`orgJikou`・`nJikou`・`nMoku` は、事項要求の検知（`docs/guides/jikou-youkyu.md`）と事項・目の年度推移（`docs/guides/trend-detail.md`）の build が出す JSON を、画面があとから合流させる（この build は出さない）。

## 具体例（FY2026 の消費者庁共通費）

`kou.csv` の 1 行（FY2026）: 一般会計、所管コード 19、所管 内閣府、組織 消費者庁（出所 目次）、項名 消費者庁共通費、項コード 010、前年度予算額 5,212,333、要求額 5,459,347、増減 247,014（千円）、頁 5、PDF頁 7（根拠 `項`）、階層 `toc`、複数書 0、`MOF突合(参考)` = `MATCHED`。

画面用 JSON の同じ項は 1 行で、5 年度分を持つ（`req` は要求額、千円）: FY2023 4,400,525、FY2024 4,991,087、FY2025 5,281,126、FY2026 5,459,347、FY2027 6,083,277。FY2027 の前年度予算額は 5,585,108 で、これは予算書 FY2026 の当初予算額（突合の例と同じ `kou-general:125`）と一致する。概算要求書の「前年度予算額」は、前年度の当初予算額。
