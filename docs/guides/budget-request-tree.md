# 概算要求書の木（項・事項・目）

概算要求書の目次・総表・明細表の CSV の行から、所管・会計・組織・勘定 › 項 › 事項 › 目の木を作る規則。実装は `packages/core/src/request-tree.ts`（項・事項）と `packages/core/src/request-detail.ts`（項の範囲と目）、CSV と金額の読み方は `packages/core/src/csv.ts`。

名前は `nameKey`（`docs/guides/names.md`）で揃えてから比べ、木に持つ。コードの区切りのハイフン類は、どれでもよい（`normalizeCodeHyphen` と同じ字の集合）。

## 入力

1 つの書（source。PDF の分冊ごと）ごとに、次の CSV がある。どれも原本の形で、1 行 = PDF の 1 行。

| CSV | この処理が読む列 |
|---|---|
| 目次 | `区分`（見出しまたは事項の文字）、`要求番号`、`ページ` |
| 総表 | `row_type`、`区分`、`要求番号`、`source_page`、`明細書頁数`、`…概算要求額_計`、`前年度予算額_計` |
| 明細表 | `row_type`、`事項`（名前の列）、`要求番号`、`source_page`、`…概算要求額`、`前年度予算額` |

- 額の列は名前の末尾で探す（列名の前に `８年度` のような年度が付くため）。総表は `概算要求額_計`、明細表は `概算要求額` で終わる列。明細表の `一般行政経費`・`その他の経費` の列は使わない。
- `row_type` の値と意味:

| `row_type` | 形 | 意味 |
|---|---|---|
| `CODE3` | `017 地球温暖化対策推進費` | 項の見出し、または事項の下の見出し（下の規則で見分ける） |
| `DETAIL` | `01‑95 地球温暖化対策の推進に必要な経費` | 事項。コードの前半は事項の番号、後半は主要経費別分類 |
| `CODE_5_4_2_4` | `95016‑2111‑02‑0000 職員基本給` | 目（明細表） |
| `CODE_NN_NNNN` | `02‑0100 職員俸給` | 目の細分（明細表） |
| `CONTEXT` | `9101 東日本大震災復興特別会計` | 会計・所管の見出し（明細表）。項の範囲を閉じる |
| `CODE1` / `CODE2` | `2 エネルギー需給勘定` / `13 エネルギー対策特別会計` | 勘定 / 会計（明細表） |
| `HIER` | 同上 | 勘定（先頭 1 桁）/ 会計（先頭 2 桁）（総表） |
| `TOTAL` | `組織計` など | 合計の行（総表） |

**金額の文字**（`amount`）: カンマと空白を除き、`△` は負。空欄と数字でないものは `null` で、0 にしない。

**空のファイル:** `readCsv` は、空の文字列にも、ヘッダだけの CSV にも `[]` を返す。ファイルが無い・空・行が 0 件のどれかは区別しない。区別が要るとき（入力の欠落を 0 件として通さない）は、呼び出し側でファイルの有無とヘッダを確かめる。

## 項と事項の決め方

書ごとに、次のどれか 1 つで木を作る。`hierarchy` にどれで作ったかを持つ。

1. **目次がある書（`toc`、`buildTocTree`）:** 目次の行を順に読む。
   - `（所管） 31 環境省` の形の行は見出し。種類は 所管・会計・組織・勘定・項 だけで、それ以外の種類や、括弧で始まるのに読めない行は止める（例外）。
   - 上位の見出しが来たら、下位の所属を空に戻す（所管 → 会計・勘定・組織、会計 → 勘定・組織、勘定 → 組織）。項はそのときの所属を持つ。
   - 事項は、`NN‑NN 名前` の形で `要求番号` のある行。直前の項の下に置く。
   - どちらでもない行は数えるだけ（`unclassified`）。
2. **目次から漏れた項を総表から補う（`supplementTocTree`）:** 目次が項の見出しを落としている書がある（目的税を財源にした繰入の項など）。総表の項の見出しの形の行のうち、目次に無く、下の「総表の小計の構造」で項になるものを、総表で直前にある目次の項の後ろに足す（`fromTotal`）。
   - 所属は直前の項から取り、頁は総表の `明細書頁数`。
   - 目次がその項の事項を前の項の下に置いているとき（補った項の範囲の総表の事項に、同じ名前がある）は、事項を補った項に付け替える。
3. **目次の無い書で、総表がある（`position`、`buildPositionTree`）:** 項は、`CODE3` の次の行が `DETAIL` で、総表の小計の構造で項になるもの。事項は、続く `DETAIL`。勘定は `HIER` の先頭が 1 桁、会計は先頭が 2 桁で、名前が予算書の特別会計名に当たるもの。組織は使わない。
4. **目次も総表も無い書（`position_detail`、`buildPositionTreeFromDetail`）:** 明細表の行の並びで作る。項は `CODE3` の次が `DETAIL`、勘定は `CODE1`、会計は `CODE2` の 2 桁で特別会計名に当たるもの。

**総表の小計の構造**（`totalTableKouHeads`）: 総表の項の行の額は、次の項までの事項の額の合計（小計）。事項の下の見出しも `CODE3` の次が `DETAIL` の形をとるが、項の小計の途中にある。そこで、項の見出しの形の行を次のように分ける。

- 項の一覧（目次の項）に、コードと名前で一致するものは項。一覧の順に照合する（前に照合した項より後ろだけを探す）。
- 一覧に無いものは、次をすべて満たすときだけ項。
  - 直前の項が無い（書・勘定の最初）か、直前の項の額が、その項からこの行までの事項の額の合計（間の `CODE3` は飛ばす）に等しい。
  - 一覧がある書では、さらに、この行の額が、次の `CODE3` までの事項の額の合計に等しい。
- `TOTAL`・`HIER` の行で、直前の項は切れる。範囲の事項の額に空欄があれば、等しいとは見なさない。

## 項の範囲と目（`walkRows`）

明細表（名前の列は `事項`）または総表（`区分`）の 1 つのファイルの行を、項の一覧に沿って順に読む。

1. `CODE3` の行で、コードと名前が、一覧の中で前に照合した項より後ろにあれば、その項の範囲を始める。
   - 組織と項が同じ名前の機関（衆議院・人事院など）は、組織の行の直後に同じコード・名前の行が続く。後の行を項とする（`sameNameOrg` に記録）。
2. 一覧に無い `CODE3` で、次の行が `DETAIL` のものは、次の両方を満たすとき、一覧に無い項として範囲を切る（`unlisted` に記録。範囲の持ち主は `{ unlisted: 項の鍵 }`）。
   - 範囲の外にいるか、今の項よりコードが大きい（項コードは組織の中で増える）。
   - 次の事項が、目次で今の項の事項になっていない。
3. それ以外の `CODE3` は事項の下の見出しで、範囲を変えない。`CONTEXT` の行で範囲を閉じる。
4. 事項は範囲の中の `DETAIL`。目は、事項から次の事項・項までの `CODE_5_4_2_4`。事項の行より前の目は `mokuNoJikou`、範囲の外の目は数えるだけ（`orphan`。最初の項より前 / `CONTEXT` の後）。

**目のコード**（`parseMoku`）: `c1`（主要経費 2 桁＋目的別 3 桁）- `x` - `yy`（目別）- `zz`。`x` の桁数は会計で違い、中央の桁が欠けた形（`95016‑ 111‑02‑0000`）もそのまま持つ。区切りの後の空白は詰める。

**目の額:** 目の行の額。目の行が空欄で、すぐ下の細分（`CODE_NN_NNNN`）に額があるときは、細分の合計（`subReq` / `subPrev`）を使う（`mokuReq` / `mokuPrev`）。目の行に額があれば、細分は内訳なので足さない。

**目の集計**（`groupMoku`）: 同じ事項の中で、同じ目（`c1` + `yy` + 目名）を、事項の下の見出しをまたいで足す。細分の合計を使った行の数（`fromSub`）と、額の無い行の数（`blanks`）を数える。どの行にも額が無ければ、額は `null` のまま。

## 検算

テスト: `packages/core/src/request-tree.test.ts`、`packages/core/src/request-detail.test.ts`、`packages/core/src/csv.test.ts`。

具体例（`request-tree.test.ts` の総表。環境省の一般会計の形）:

```text
CODE3   017 地球温暖化対策推進費                              100   ← 目次の項
DETAIL  01‑95 地球温暖化対策の推進に必要な経費                  60
CODE3   006 二国間クレジット制度の構築等事業                     40   ← 017 の小計 100 ≠ 60。事項の下の見出し
DETAIL  11‑13 気候変動の影響への適応策に関する調査研究に必要な経費 40
CODE3   019 石油石炭税財源エネルギー対策特別会計へ繰入          1648   ← 017 の小計 100 = 60 + 40、自分 1648 = 1648。目次に無い項
DETAIL  01‑63 石油石炭税財源のエネルギー需給勘定へ繰入れに必要な経費 1648
CODE3   020 脱炭素成長型経済構造移行推進エネルギー対策特別会計へ繰入 0  ← 目次の項
DETAIL  01‑63 脱炭素成長型経済構造移行費用の繰入れに必要な経費     0
TOTAL   組織計                                               1748
```

目次が 019 の事項（要求番号 6）を 017 の下に置いていても、`supplementTocTree` は 019 を 017 の後ろに足し、事項 6 を 019 に付け替える。
