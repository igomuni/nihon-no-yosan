# 予算の一生の画面の「事項」タブ（`#/lifecycle`）

項の下の事項（予算書の当初予算と補正）を、年度をまたぐ確定した対応でそろえて、年度の列に並べる。右ペインのタブ「1年の推移 / 年度推移 / 事項」の 3 つ目。実装は `packages/core/src/lifecycle-jikou.ts`（純粋な関数。テストあり）、`apps/web/src/lifecycle/LifecycleJikouTab.tsx`、データは `packages/pipeline/src/build/lifecycle-jikou.ts`。

```bash
npm run build:data   # lifecycle/jikou.json.gz を、予算の一生の表と一緒に作る
```

## 何を出すか・出さないか

| 段階 | 事項の単位 |
|---|---|
| 概算要求 | **無い**（要求側の事項は、予算書の事項との結びつけを確かめてから足す。未実装） |
| 政府案（当初予算） | FY2017〜FY2026 |
| 補正 | FY2017〜FY2024（補正の事項の CSV。`mof-history.md`） |
| 決算 | **無い**。決算は項と目の単位で、事項の列が無い。予算書に事項 × 目の額も無いので、目を事項の下には結ばない |

値は 4 つ（千円）: `政府案`、`補正後`（改予算額）、`補正の差引額`、`前年度予算額`（予算書が載せる）。切り替えて見る。値が無いセルは `—`（0 とは別）。補完しない（補正の記録が無い事項に、政府案の額を補正後として入れない）。

## データ（`lifecycle/jikou.json.gz`。タブを初めて開いたときに読む。約 0.6MB）

```text
{ years: number[],
  kous:  string[],      // 項の id（`LifecycleKou.id`）。事項のある項だけ
  nodes: [項の添字, 年度, 事項名, 政府案, 前年度予算額, 補正後, 補正の差引額][],   // 千円。値が無ければ null
  links: [前の年度の事項, 次の年度の事項, 根拠のビット, 額の確認の添字][] }          // 確定（RESOLVED）した対応だけ
```

- 事項は、`buildJikouLinkData`（`jikou-links.ts`。`mof-history.md` の「事項の年度をまたぐ対応」）の `nodes` と、下の「補正にだけある事項」。対応は、その `links` のうち `RESOLVED` と、補正にだけある事項の対応。
- 事項を項に結ぶ鍵は、年度・会計・所管（特別会計は特別会計）・組織（特別会計は勘定）・項コード・項名を `nameKey` でそろえたもの。概算要求のみの項（予算書の項コードが無い）は、事項が無い。
- 根拠のビットは `JIKOU_EVIDENCE` の添字、額の確認は `JIKOU_AMOUNT` の添字（`lifecycle-jikou.ts`）。
- 結べない事項（項が見つからない）があれば、`build:data` は止まる（捨てない）。重なる項の鍵も止まる。今は 0 件。

### 補正にだけある事項

補正の事項の CSV には、当初予算に載っていない事項（補正で新しくできた事項）がある。年度ごとに 10・33・21・30・39・21・11・28 件（FY2017〜FY2024。計 193 件）。額は、FY2020 の改予算額の合計が 28.9 兆円（特別定額給付金給付事業の助成に必要な経費 12.9 兆円など）、FY2021 が 13.4 兆円、FY2022 が 20.0 兆円で、小さくない。

- `nodes` に、政府案 = null、補正後・補正の差引額あり、として入れる（`jikouSuppOnly`）。画面では、政府案・前年度予算額の合計と行の数には数えない（当初予算の項の額と比べるため）。
- 対応は、隣り合う年度の同じ鍵の事項とだけ結ぶ（`linkSuppOnly`。`same_key`）。すでに確定した対応が出入りしている事項には足さない。名前だけ・額だけの候補は探さない。187 組。
- `jikou-links` の件数・継続年数（`mof-history.md`）は変えない。補正にだけある事項は、そこには含めない。

## 画面

- 行 = 事項（年度をまたぐ確定した対応でそろえた 1 本）。列 = 選んだ項の年度の並びのうち、事項のある年度。行の並びは、最後の年度の政府案の額の降順、続けて、その年度に無い行（最後にあった年度の新しい順）。名称が変わった行は事項名を色付きにし、行の年度の範囲が列より狭ければ、範囲を添える。
- 下に「事項の計」と「項の額」。事項の計は、値のある事項だけの合計で、一部の事項にしか値が無い年度は `n/m 事項` を添える。項の額（予算書の目の合計）と合わなければ、色を付けて「事項の計と違う」と出す。
- 行を押すと、その事項の年度ごとの値（4 つ）と、前の年度との対応の根拠（確定したものだけ）。年度の列の見出しを押すと、その年度の項に移る。
- 「この表にないもの」: 概算要求の事項、事項の単位の決算、FY2025 以降の補正、補正が複数回の年度の扱い。

## 確かめたこと（動かした出力から）

事項 16,456 件（当初予算 16,263 + 補正にだけある 193）、対応 14,144 組。事項のある項 10,370。FY2017〜FY2026 の全項・全年度で、事項の計を項の額（`lifecycle/data.json.gz` の項の値）と比べた。

| 値 | 事項の計 = 項の額 | 違う | 一部の事項にだけ値 | 項に値があり、事項に 1 つも無い |
|---|---:|---:|---:|---:|
| 政府案 | 10,528 | 0 | 0 | 0 |
| 前年度予算額 | 10,523 | 0 | 0 | 5 |
| 補正後 | 6,408 | 0 | 63 | 4,057 |
| 補正の差引額 | 6,364 | 44 | 63 | 4,057 |

- **「事項に 1 つも無い」（補正後 4,057）:** FY2025・FY2026 の補正（補正の事項が無い）と、補正の事項の CSV で `項のみ` の行（その項に事項の行が無い）の項。画面は `—`（項の額だけ出す）。
- **補正の差引額の 44 項:** 補正が複数回ある年度（FY2018 など）で、項の差引額は「項が載る最後の回」（`項のみ` の行を含む）、事項の差引額は「その事項が載る最後の回」の値。回が違うので合わない（例: FY2018 沖縄教育振興事業費、事項 2,467,273 千円、項 0）。補正後は、どちらも最後の回の改予算額で一致する。

具体例（FY2020 厚生労働本省「失業等給付費等労働保険特別会計へ繰入」、千円）: 事項 3 件。

| 事項 | 政府案 | 補正後 | 補正の差引額 |
|---|---:|---:|---:|
| 育児休業給付金の財源…繰入れに必要な経費 | 8,628,000 | 8,628,000 | 0 |
| 失業等給付費等の財源…繰入れに必要な経費 | 18,831,500 | 24,736,500 | 0 |
| 雇用安定事業費の財源…繰入れに必要な経費（補正にだけある） | — | 727,501,506 | 410,292,578 |
| **事項の計 = 項の額** | 27,459,500 | 760,866,006 | 410,292,578 |

（政府案の計は、補正にだけある事項を数えない。FY2020 の補正は 3 回。2 行目の差引額 0 は最後（第 3 回）の値で、第 2 回に 5,905,000 を追加している（補正後 = 最後の回の改予算額なので、累計）。）

## 限界・未確認

- 概算要求の事項は、まだ出していない。予算書の事項との名前での結びつけの割合を、先に測る必要がある（`mof-ui.md` の突合率は目のもの）。
- 事項の対応は名前と額の根拠によるので、事業が同じとは限らない（`mof-history.md`）。確定しない事項は別の行になる。
- 画面の自動テストは無い。画面は、基準データから作った JSON で動かして確かめた（項の事項タブ、補正にだけある事項を含む項）。
