# 画面の「RS」タブ（行政事業レビューの事業の一覧）

予算の推移の画面（`#/lifecycle`）の中ペインに、RS の事業の一覧を出す。**予算書の項・目に結べるかどうかに関係なく、全事業を出す。** 結べた事業には、結べた項・目を添える（つなぎ方は `rs-link.md`）。

## データ `rs/jigyo.json.gz`

`npm run build:data` が、RS の CSV のディレクトリ（`data/download/rs/2025`）があるときだけ作る（`web-data-cli.ts` の第 5 引数。無ければ作らず、`about.json` に `rs` も出さない）。タブを開いたときに読む。約 0.8 MB（gzip）。

| キー | 中身 |
|---|---|
| `years` | 予算年度（2-1 に行のある年度。2025 年度版で 2021〜2025） |
| `kous` | 項の id（`LifecycleKou.id`）。`links` が指す |
| `jigyo` | 事業 1 件: `[予算事業 ID, 事業名, 府省庁, 局・庁, 主要経費（複数は `\|` でつなぐ）]`。予算事業 ID の数字の順 |
| `amounts` | 事業 × 予算年度: `[事業の添字, 予算年度, 当初予算, 補正予算, 前年度からの繰越し, 予備費等, 歳出予算現額, 執行額, 翌年度への繰越し, 翌年度要求額]`（円。空欄は null） |
| `links` | 項に結べた行（2-2 の `linked`）: `[事業の添字, 予算年度, 項の添字, 目名, 予算種別, 予算額（円。空欄は null）]` |

作り方（`rs-jigyo.ts`）:

- **事業**: 1-2（事業概要等）から、予算事業 ID ごとに 1 件。同じ ID の行が複数あるのは、主要経費が複数あって行が分かれているため（2025 年度版で 241 事業。違う列は主要経費だけ）。事業名・府省庁・局・庁が同じことを確かめ、主要経費を合わせる。違えば止まる。
- **額**: 2-1（サマリ）の、会計区分が空の**合計の行**（「当初予算(合計)」などの列）。会計区分別の行は使わない。同じ事業・年度に合計の行が複数あるのは 17 件で、片方は全部空の行。値のない行を除き、残りが 1 つか、同じ値でなければ止まる。額は整数の円。`30000000.0` のような小数点以下が 0 の形は整数に直し、それ以外の小数は止まる。
- **つなぎ**: `buildRsLink` の `linked` の行だけを入れる。結べない行（`noKou`・`unmatched`・`ambiguous`）は入れない（事業の一覧には、結べない事業も残る）。

## 画面

- **中ペインのタブ「RS」**（`about.json` に `rs` があるときだけ。無いビルド、たとえば RS の CSV を持たない公開サイトのビルドでは、タブを隠す。保存していた表示が RS のとき、RS が無ければ「項」に戻す）。選んだ予算年度の事業（2-1 にその年度の行がある事業）の一覧。列: 府省庁・局・庁・事業名・項・当初予算・補正予算・歳出予算現額・執行額・翌年度要求額（並べ替え・列幅の変更ができる。既定は歳出予算現額の大きい順）。
  - 「項」は、その年度に結べた予算書の項の数。結べないときは「—」。
  - 上の集計: 事業の数・項に結べた事業の数・当初予算・歳出予算現額・執行額の合計（値のある事業だけ足す）。RS の合計は事業単位で、予算書の数値と一致しない（ツールチップに書く）。
  - 選んだ年度に RS のデータが無い（RS の予算年度の外）ときは、その旨を一覧に出す。
- **左のフィルタ**（中ペインが RS のとき、RS 用に切り替える）: 府省庁（複数選択。選択肢は全年度の事業から、件数は選んだ年度）、局・庁と事業名（部分一致、`.*` で正規表現）、予算書の項への結び（すべて・結べる・結べない）。
- **右ペイン**: 選んだ事業の
  - 基本情報（府省庁 › 局・庁、予算事業 ID、主要経費）
  - 予算・執行の年度推移（折れ線は当初予算・歳出予算現額・執行額、棒は前年度繰越・翌年度繰越の右目盛り。`TrendChart` の `labels` で系列の名前を RS の名前にする。**翌年度要求額は、翌年度の要求なので、折れ線には載せない**）
  - 年度ごとの額の表（当初予算・補正予算・前年度繰越・予備費等・歳出予算現額・執行額・翌年度繰越・翌年度要求額。行を押すと、その年度に移る）
  - 選んだ年度の予算書の項・目（項ごとに、目名・予算種別・予算額。「この項の詳細を開く」で、その項を項の一覧・詳細で開く）。結べた行が無いとき、その事業が選んだ年度の RS に無いときは、その旨を出す。
- **キー操作**: 一覧は J / K で行の選択、右ペイン（H / L で移る）は J / K で年度の切り替え。ほかのタブと同じ（`budget-lifecycle.md`）。年度を移すと中ペインの年度も移る。
- **出典**: RS のタブを開いているとき、画面下の出典に「行政事業レビュー見える化サイト（https://rssystem.go.jp）」を足す。「出典と利用条件」のページに、RS の節（出典・加工したこと・利用条件のリンク・事業数・予算年度）を出す。

## 公開

RS の CSV のうち 3 ファイルを、リリース（タグ `dataset-rs-v0`）に置き、公開サイト（GitHub Pages）のビルドが、それを取り込んで `rs/jigyo.json.gz` を作る（`web-publish.md` の「RS のデータ」）。取り込めないビルド（手元で RS の CSV を持たないときなど）では、RS のタブは出ない。
