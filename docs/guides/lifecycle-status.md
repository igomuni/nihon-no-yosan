# 予算の一生の画面: 値の無い段階の見せ方と、値のある段階の絞り込み

予算の一生の画面（`#/lifecycle`。仕様は `budget-lifecycle.md`）で、概算要求・政府案・補正・決算のどれかに値が無い項を、事実を誤認させずに見せるための決まり。実装は `packages/core/src/lifecycle-status.ts`（値のある段階の絞り込み）、`apps/web/src/lifecycle/`（画面）。純粋な関数で、テストがある。

**廃止した表示（2026-10-29）:** この文書には、以前、項の詳細の「段階ごとの状態」（段階ごとに、値が無い理由のラベルと判定の根拠を出す表示）、1 年の推移のグラフ（段階ごとの額・増減・現額の使われ方）、中ペインの「集計」タブ（観測額と、2 つの段階の比較）の決まりを書いていた。画面から無くなったので、書かない（履歴は git にある）。

## 原則

- **値が無いことと、0 は別。** 観測した値が 0 の段階は `0円`、値が無い段階は `—`。どちらも補完しない（補正の記録が無い項に、政府案の額を「補正後」として入れない。前後の値からの補いもしない）。
- **現行データに値が無いことと、公式の資料にその項が無いことは別。** 後者は断定しない。画面は、現行データ（基準データから作った CSV と、その突合の結果）で確かめられることだけを書く。
- **理由が判定できないときは、理由を作らない。**
- 項の金額（予算書の政府案・補正・決算）は、目の行の合計なので、導出した値（`derived`）。

## 一覧の絞り込み（値のある段階）

年度・会計・検索で絞った項に対して、次の件数を出し、選んで絞れる（左のフィルタ。`LIFECYCLE_PATTERNS`）。

| 絞り込み | 定義 |
|---|---|
| すべて | — |
| 全段階に値あり | 概算要求・政府案・補正・決算のすべてに値がある（FY2024 で 887 項） |
| 一部の段階に値なし | どれかの段階に値が無い。理由は問わない（402） |
| 政府案の値なし | 政府案の CSV に同じ鍵の行が無い（255） |
| 概算要求のみ | 概算要求書にだけある項（予算書の項に結べていない。予算書が基準データに無い年度の項を含む） |
| 決算の値のみ | 決算にだけ値があり、概算要求・政府案・補正のどれにも値が無い（230） |

理由が分かっているかどうかは、絞り込みに使わない。理由のある欠落も、「全段階に値あり」には入らない。

## 判定できないこと（しない表示）

- 年度をまたぐ対応（`links`。`budget-lifecycle.md`）は、一覧の「対応」列に、状態（確定・未確定・候補なし）と根拠を出す。「対応未確定」の絞り込みは、確定以外の項。名前だけの候補を、同じ項と断定しない。
- 政府案が無い項（補正・決算にだけある項）の概算要求は、予算書の項に結べていない。名前が違うだけで、実は政府案の項と同じ項かもしれないが、それを確かめる根拠は今のデータに無い。
- 補正の記録が無い項について、決算の歳出予算額は政府案と全件一致する（FY2023・FY2024。`budget-lifecycle.md` の検算）。それでも、画面は政府案の額を補正の観測値として出さない。

## 未確認

- 年度をまたぐ対応は、隣り合う年度の組だけ。会計をまたぐ移管は探していない。
- 概算要求のみの項は、予算書の項と結べていないので、政府案・補正・決算の値が無い。予算書に対応する項があるのに、名前が違って突合できていない項も、ここに入っている可能性がある（確かめていない）。
- 補正の号の区別（原本に無い）。
- 事項の単位の表示は、中ペインの「事項」（`lifecycle-jikou.md`）。事項の単位の決算は無い。
