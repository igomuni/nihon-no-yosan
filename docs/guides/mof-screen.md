# 概算要求と当初予算の差の画面（`#/mof`）

概算要求額と、予算書の当初予算額（国会への提出時の政府案）を、項ごとに並べて見る画面。データは `mof-ui.md`。実装は `apps/web/src/mof/`、絞り込み・並べ替えは `packages/core/src/mof-view.ts`（純粋な関数。テストあり）。年度推移（`trend-screen.md`）とは別のページで、年度推移には予算書との突合を混ぜない。

```bash
npm run build:data   # 画面が読む JSON を apps/web/public/data/ に作る
npm run dev          # http://localhost:5173/#/mof
```

## データ

ブラウザが静的ファイルを直接読む。`mof/kou.json.gz` で一覧と分布図を出し、`mof/detail.json.gz`（事項・目の内訳）は一覧のあとに読む。対象は FY2023〜FY2026（FY2027 は予算書が無い）。

## 画面

年度推移と同じ 3 ペイン（フィルタ・一覧または分布図・詳細）。ペインと列の幅はドラッグで変えられる。

- **行:** 1 行 = 年度 × 予算書の項（`mof-ui.md`）。種類は 対応あり / MOFのみ / 概算要求のみ / 額0の項。既定は額0の項以外。
- **差** = 当初予算額 − 要求額（正なら要求より予算が大きい）。差率 = 差 ÷ 要求額。既定の並びは差の降順（符号つき）。
- **一覧の列:** 所管、会計、組織／勘定、項名（型のバッジ）、事項数、目数、要求額、当初予算額、差、差率。事項数・目数は、概算要求と予算書を名前でつないだ和集合（目は事項をまたいで数える）。組織の事項要求は、組織の列のバッジにする。上位 600 件まで出す（選んだ項が外にあれば、そこまで出す）。
- **所管:** 年度推移と同じく、要求書の公開元の府省（PDF のドメイン由来）。内閣府の外局（こども家庭庁・消費者庁・金融庁など）は、予算書の所管が内閣府でも、それぞれの府省になる。要求書の無い行（MOFのみ）は予算書の所管で、特別会計は予算書の共管所管名があればそれ。複数の府省の会計の列挙（「、」「及び」）は府省に分ける。複数所管の行（府省が 2 つ以上）は「N所管」とし、府省名はツールチップと詳細に出す。同額（同じ特別会計の要求書全体を、所管の各府省がそれぞれ載せている。データから主の府省は決められない）と、合計（東日本大震災復興。各省が持ち分を載せ、復興庁の書が合計）の 2 種類がある。
- **分布図:** 横軸は概算要求額、縦軸は当初予算額で、どちらも対数（千円）。対角線は「要求 = 当初」で、それより上は予算が要求を上回った項。0 の値は、軸の外側の帯に置く（対数で描けないため）。要求か予算の無い行（MOFのみ・概算要求のみ）は描かない。色は 3 つ: 編成で決まる項 / 金額を示さない要求を含む（事項要求・要求額0・一括計上の配分先）/ 通常の要求（中身を積み上げて要求し、査定された項。差を査定の結果として読めるのは主にこれ）。3 つともデータとしては正常で、額の決まり方の区別。点にマウスを載せると項名・要求額・当初予算額・差、クリックで詳細。フィルタは一覧と共通。

## フィルタ

所管（府省ごとと「複数所管」）、会計、組織／勘定と項名の検索（部分一致、`.*` で正規表現。項名は予算書の項名も見る）、行の種類、差の大きさ（|差| が 1 億・10 億・100 億円以上、差率 ±10%）、編成で決まる項を除く、差の理由の型（どれかを持つ項）。件数は選択年度のもの。

## 詳細

タブ「項 / 事項 / 目」。ラベルに事項・目の数（両側の和集合）。

- **項:** 要求額・当初予算額・それぞれの前年度予算額・差、要求書へのリンク（`#page=`）、型の説明（事項要求には備考の行を添える）。前年度予算額は、概算要求書が前年度の当初予算額、予算書が前年度の補正後の額で、補正のあった項では違う（注記を出す）。
- **事項・目:** 名前・要求額・当初予算額・差・差率の表と計。片側にしか無い行は、無い側を「—」にし「要求のみ」「予算のみ」の印。目は名前の下にコード。計が項の額と合わないときは差を注記する（要求書の明細表の読み取りの欠け。年度推移の目タブと同じ）。

## 差の理由の型

読み方の手がかりで、理由を確定するものではない。付け方は `mof-ui.md`。バッジの色と説明は `apps/web/src/mof/typeInfo.ts`。編成で決まる項（予備費・国債費・地方交付税交付金・地方特例交付金・繰入）は、要求の額が仮の値で、差は査定の結果ではない。

## 保存

年度、一覧 / 分布図の表示、詳細のタブ、フィルタ、並べ替え、選んだ項、ペインと列の幅は、ブラウザの localStorage（キーは `mof:*`）に保存する。保存できなくても動く。フィルタは保存値を既定値の上に重ねて読む（項目が増えても欠けない）。年度を替えると選んだ項は外す。

## 検算

- 絞り込み・並べ替えは `packages/core/src/mof-view.test.ts`（前のリポジトリのテスト 6 件）。
- 画面は、基準データから作った JSON で動かして確かめた。FY2026 の一覧は 1,093 件で、種類別の件数は対応あり 1,035、MOFのみ 49、概算要求のみ 9（額0の項 42 は既定で隠す）で `mof-ui.md` と一致。分布図に描く点は 1,035（型の別 126 / 59 / 850）で、描かない 58 件は要求か予算の無い行。画面の自動テストは、まだ無い（未確認）。

- core の関数名を、年度推移の関数との重複を避けて `mof` を付けた名前にした（例: `mofDiffOf`、`mofGroupOf`、`MOF_KIND_LABEL`）。
