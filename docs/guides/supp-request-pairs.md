# 補正予算の追加額と、翌年度の概算要求の額が近い項

グラフで、補正予算の額と、次の年度の概算要求の額が近い項がある。その項を一覧（`datasets/reference-v0/supp-request-pairs.csv`）にして、型に分ける。事項で似た現象を調べるときの手がかり。

```bash
node packages/pipeline/src/build/lifecycle-cli.ts data/dataset/reference-v0 <出力ディレクトリ> data/dataset/mof-history-v0
node packages/pipeline/src/build/supp-request-pairs-cli.ts <出力ディレクトリ> datasets/reference-v0/supp-request-pairs.csv
```

実装は `packages/core/src/supp-request-pairs.ts`（`suppRequestPairs`。純粋な関数。テストあり）。入力は、予算の一生の表（`budget-lifecycle.md`）の `kou.csv`・`events.csv`・`links.csv`。

## 何を比べるか

- 対象は、年度をまたぐ対応が `RESOLVED` で、相手が 1 つに決まる項（FY2022〜FY2026 の補正。概算要求は FY2023 以降にしかない。FY2026 の補正は、予備費の 1 項だけ）。
- 補正側: `supp.supp_add`（補正の追加額）が正の項。
- 要求側: 翌年度の `request.request_amount`（要求額）と、`request.request_prev`（要求書の前年度予算額）。**増額分** = 要求額 − 前年度予算額。
- 補正追加額が、増額分または要求額と **±5% 以内**の項を載せる（65 項。完全一致 13 項）。要求は前年の 8 月、補正は 12 月なので、時期は要求が先。

## 型

型は、上から順に当てはめ、最初に当たったものとする（`classifySuppRequest`）。±5% は、すべて「基準の値に対する差」。

| 型 | 当てはめ | 項数 |
|---|---|---|
| 要求が前年度予算に近い | 要求額が、要求書の前年度予算額、または補正年度の当初予算に近い | 14 |
| 当初予算0で補正と要求が一致 | 補正年度の当初予算が 0 | 9 |
| 補正追加額が当初予算に近い | 補正追加額が当初予算に近い | 1 |
| 補正が主財源で、要求は補正後予算と同水準 | 要求額が補正後予算に近く、当初予算が無い、または補正追加額が当初予算の 2 倍以上 | 9 |
| 要求が補正後予算と同水準 | 要求額が補正後予算に近く、補正追加額が当初予算の 2 倍未満 | 17 |
| 要求が補正追加額と同額で、当初予算を上回る | 要求額が補正追加額に近く、当初予算の 1.1 倍を超える | 4 |
| 補正追加額に近いが、補正後予算とも当初予算とも離れる | 上のどれでもない | 11 |

上の 3 つは、補正との関係とは言えない（要求が前年度予算の延長、または当初予算に近い）。下の 4 つが、見るべきもの。基準（±5%、2 倍、1.1 倍）は、41 項を 1 項ずつ見て決めた。

- **補正が主財源で、要求は補正後予算と同水準（9）:** 大学入試センター施設整備費、環境調査研修所施設費、国立長寿医療研究センター施設整備費、日本原子力研究開発機構施設整備費など。当初予算がほぼ無く、補正で措置した額と同額を、翌年度に要求する。
- **要求が補正後予算と同水準（17）:** 担い手育成・確保等対策費（補正後予算 202,304、要求 202,769 百万円）、財務局業務費、農林水産本省共通費など。補正追加額は当初予算の数%〜数十%で、要求額と補正後予算の差は 0〜2% に収まるものが多い。
- **要求が補正追加額と同額で、当初予算を上回る（4）:** 森林整備・林業等振興対策費、北海道開発行政推進費、日本スポーツ振興センター施設整備費、国立児童自立支援施設整備費（FY2025 の補正）。
- **離れる（11）:** 男女共同参画社会形成促進費（当初予算・補正追加額・要求が、いずれも約 1,500 百万円）、予備費（要求が毎年 5,000 億円）など。金額が近いだけと考えられる（要因は未確認）。

## 列（`supp-request-pairs.csv`。1 行 = 補正年度の項）

| 列 | 内容 |
|---|---|
| `補正の年度` `会計` `所管` `組織` `特別会計` `勘定` `項コード` `項名` | 補正年度の項（`kou.csv`） |
| `補正追加額(円)` | 補正の追加額 |
| `翌年度の要求額(円)` `翌年度の要求書の前年度予算額(円)` `翌年度の要求増額(円)` | 翌年度の概算要求。増額 = 要求額 − 前年度予算額 |
| `一致した値` `完全一致` `補正追加額の差(%)(一致した値に対して)` | `要求増額` / `要求額` / `要求増額+要求額`。増額分に当たる場合は増額分に対する差、そうでなければ要求額に対する差 |
| `補正年度の当初予算(円)` `翌年度の当初予算(円)` `翌年度の補正追加額(円)` | 無ければ空 |
| `要求額が翌年度の前年度予算額に±5%で近い` `要求額が補正年度の当初予算に±5%で近い` `補正追加額が補正年度の当初予算に±5%で近い` `補正年度の当初予算が0` | 型を決めた条件（`はい` / 空） |
| `要求額と補正後予算の差(%)` | 補正年度の補正後予算に対する、翌年度の要求額の差 |
| `分類` | 上の型 |
| `補正年度のkou_id` `翌年度のkou_id` | `kou.csv` の鍵 |

## 全体での確かめ（手元の集計。CLI には入れていない）

補正追加がある 2,025 項（1 対 1 でつながり、翌年度の要求がある）で、翌年度の要求額が ±1% に収まる数を、要求額を項の間で入れ替えた場合と比べた。

| 翌年度の要求額が近い値 | 実測 | 入れ替えた場合（50 回の平均） |
|---|---|---|
| 当初予算 | 302 項（14.9%） | 4.5 |
| 補正後予算 | 137 項（6.8%） | 4.4 |

- 補正追加額と要求額の順位相関は 0.5〜0.6 だが、当初予算の規模を除くとほぼ 0（−0.06〜0.11）。規模が大きい項ほど、どちらも大きいだけ。
- 補正後予算に ±1% で近く、当初予算から 5% 以上離れる項は 34 項。
- 補正追加額と翌年度の要求額が **完全一致** する項は、補正の翌年度の要求にだけ現れる（補正と同じ年度、翌々年度の要求には、ほぼ無い）。

## 注意と未確認

- **補正が要求を先取りした、という読みは推測。** 要求（8 月）が先で、補正（12 月）が後。補正で措置される経費が、要求にも同額で計上される、と読める。要求書の記述（備考欄など）は確かめていない。
- 載せるのは、対応が `RESOLVED` で 1 つに決まる項だけ。`AMBIGUOUS`・`UNRESOLVED` の項、複数に分かれる項は含まない。
- 概算要求は FY2023 以降のみで、FY2027 の要求は項コードが空欄。補正と比べられるのは FY2022〜FY2026 の補正（FY2026 の補正は、予備費だけ載っている）。
- 「離れる」型の要因は未確認。
- 事項・目での確認は、まだしていない。補正の額が、項の単位でしか出ていない。
