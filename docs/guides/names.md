# 名前の表記の揃え方

概算要求書（PDF から取った文字）と、財務省の予算書（CSV・XML）の名前（項・事項・目）を比べるときの揃え方。実装は `packages/core/src/names.ts`。

## 規則

比べる前に、次の 3 つだけをする。それ以外の正規化・部分一致・読み替えはしない。

1. **幅の統一**（`fold`）
   - 全角の ASCII 相当（U+FF01〜FF5E）を ASCII にする（例: `Ａ４` → `A4`、`（` → `(`）。
   - 半角のカナ・約物（U+FF61〜FF9F）を NFKC で全角にする（例: `ｶﾅ` → `カナ`）。
   - それ以外の互換文字（`①` `Ⅱ` など）は変えない。
2. **PDF の外字を字にする**（`fold` の中、`PDF_GAIJI`）
   - 私用領域（U+E000〜F8FF）のコードのうち、予算書の同じ名前で字を確かめたものだけを置き換える。確かめられないものは、そのまま残す。
3. **空白を除く**（`nameKey`）: 半角・全角の空白を除く。

原本の値は書き換えない。CSV には原文のまま持ち、比べるとき・画面に出すときに揃える。

コードの区切りのハイフン類（U+2010〜2015・U+2212・U+FF0D）は `normalizeCodeHyphen` で `-` に揃える。名前には使わない。

## PDF の外字

- 概算要求書の PDF には、作成環境の利用者定義のフォントで、私用領域のコードに字を割り当てたものがある。PDF からテキストを取ると、そのコードのまま出る（ブラウザでは表示されない）。
- コードと字の対応表は PDF に無い。予算書に同じ名前があって字を確かめられたものだけを、対応に足す。
- 確かめた対応:

| コード | 字 | 確かめた名前（予算書） |
|---|---|---|
| U+E5E3 | 填 | 貨幣交換差減補填金、償還差額補填金、…減収補填特例交付金 |

- 名前（項・事項・目）に出る外字は、FY2023〜FY2027 の概算要求書で、ほぼ U+E5E3 だけ。外字の大半は備考の積算内訳の中にある（例: U+EF63 は「A4 500 枚 × 5 冊」の「×」の位置。字は確かめていないので置き換えない）。

## 検算

`packages/core/src/names.test.ts`:

- `fold('Ａ４（ｶﾅ）')` → `A4(カナ)`、`fold('①Ⅱ')` → `①Ⅱ`
- `fold('貨幣交換差減補\uE5E3金')` → `貨幣交換差減補填金`、確かめていない U+EF63 は残る
- `nameKey('消費者庁\u3000共通費 ')` → `消費者庁共通費`
