# 概算要求書の黒塗り頁

概算要求書の PDF には、備考欄の説明や金額を、黒い四角で塗りつぶした頁がある。その頁を一覧（`datasets/reference-v0/redacted-pages.csv`）にして、属する項を示す。

```bash
node packages/pipeline/src/build/redacted-pages-cli.ts data/dataset/reference-v0 <PDF の置き場> datasets/reference-v0/redacted-pages.csv
```

PDF の置き場は、記録の `localPdfPath` の先頭 `data/download/` に当たるディレクトリ。`pdftoppm`（poppler）が要る。FY2023〜FY2027 の全 681 本、44,806 頁を調べて、8 並列で 1.5 分ほど。

## 見つけ方

- 頁を 25dpi のグレー画像にして、**黒い面**（3 行 × 9 列の窓が、すべて暗い画素（階調 50 未満）の位置）の数を数える（`packages/core/src/redacted-pages.ts` の `solidDark`。テストあり）。文字・罫線は細く、窓が埋まらない。黒く塗りつぶされた四角だけが数えられる。
- 数が 150 以上の頁を、黒塗りの頁とする（約 8mm × 2mm の塗りつぶし 1 つ分）。
- 属する項は、概算要求の項の表（`trend.ts` の `kou.csv`）の `PDF頁`（項の開始頁）から決める。同じ書の項を開始頁の順に並べ、頁以下で最も大きい開始頁の項（`kouOfPage`）。

## 列（`redacted-pages.csv`。1 行 = 黒塗りの頁 × 項）

| 列 | 内容 |
|---|---|
| `年度` `要求書` `PDF頁` | 年度、書（PDF の slug）、PDF の通し頁 |
| `黒い面（窓の数）` | 黒い面の大きさの目安（大きいほど、広く塗りつぶされている） |
| `所管` `組織` `項名` `項コード` | 頁が属する項。決められなければ空 |
| `項の割り当て` | `頁の範囲`（開始頁が、明細表の項の行から決まり、頁に文字層がある）/ `頁を推定`（開始頁を推定した、または文字層が無い頁）/ `特定できず` |
| `項の開始頁` `次の項の開始頁` | 項の頁の範囲。次の項が無ければ空 |
| `PDFのURL` | 取得元の PDF |

## 画像で確かめたこと

3 つの頁（FY2025 法務省 p737、FY2024 国立国会図書館 p9、FY2023 内閣官房 `r5_08` p9）と、FY2025 内閣官房 p7 を、画像で見た。
- 公安調査庁（FY2025 p737）: 備考欄の説明と金額が、帯状に塗りつぶされている。
- 国立国会図書館（FY2024 p9）: 備考欄の、国庫債務負担行為の金額が塗りつぶされている。
- 内閣官房: 備考欄の、システムの内訳が塗りつぶされている。

## 限界

- 大きな黒い四角だけを数える。小さな塗りつぶし、灰色の網掛け、白抜きは、数えていない（見つけられていないものがありうる）。
- 項の割り当ては、項の開始頁による。画像の頁は、開始頁が推定のことがある（`頁を推定`）。
- 塗りつぶされた金額が、項の金額のうちどれだけかは、見ていない。項の金額（総表の値）は、塗りつぶされておらず、項単位では取れている。
- 33 頁のうち、画像で見たのは上の 4 頁だけ。残りは、黒い面の数だけで、塗りつぶしと判定した。
- 黒い面の閾値（150）と窓の大きさは、手元の PDF で決めたもので、独立に評価していない。
