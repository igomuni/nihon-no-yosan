# 概算要求の「金額を示さない要求」（事項要求など）の候補（FY2023〜FY2027）

概算要求書のうち、金額をすべては示していない要求の候補を、項の単位で拾う。出力は CSV（`kou.csv`、`marks.csv`）、件数の記録（`summary.json`）、画面用の JSON（`jikou.json.gz`）。実装は `packages/pipeline/src/build/jikou-youkyu.ts`、動かすのは `jikou-youkyu-cli.ts`、画面用の型は `packages/core/src/budget-request-trend.ts`（`BudgetRequestJikouData`）。

```bash
node packages/pipeline/src/build/jikou-youkyu-cli.ts data/dataset/reference-v0 <出力ディレクトリ>   # kou.csv、marks.csv、summary.json、jikou.json.gz
```

**候補であって、事項要求と確定したものではない。**

- `要求0` には、施設費の終了のように予算でも 0 のものが含まれる。`MOFとの比較(参考)` が `当初=要求` の項がそれにあたる。
- `印` の項でも、事項要求はその項の一部にすぎない。項の額の大部分は、金額で要求されている。

## 入力

| 入力 | 使い方 |
|---|---|
| 項の年度推移の `kou.csv`（`docs/guides/trend.md`） | 項の一覧、前年度予算額、要求額。CLI は基準データから作り直したものを入力にする |
| `budget-request/{年度}/detail-table/sources/*.csv` | 明細表の行の位置（`source_line_start`）と目の名前 |
| `budget-request/{年度}/plain-text/*.txt` | 備考の文字（明細表の CSV は備考を持たない） |
| 突合の `m1-kou.csv`（`docs/guides/match.md`） | 予算書の当初額と突合の状態（参考）。FY2027 は予算書の版が無いので無い |

## 形

1 つの項が複数の形を持つことがある。`形` 列では `;` で区切る。

| 形 | 条件 |
|---|---|
| `印` | 項の範囲の中に「（事項要求）」がある。空白を除いて照合し、括弧は全角でも半角でもよい。 |
| `文` | 項の範囲の中に、印以外の「事項要求」の言及がある（例: 「…財源の確保については、事項要求とする」）。 |
| `要求0` | 前年度予算額が正で、要求額が 0。 |
| `要求0・場所ごと` | `要求0` のうち、同じ場所の項がすべて要求額 0 のもの。場所は、特別会計なら特別会計＋勘定、一般会計なら所管＋組織。条件は、項が 2 つ以上あり（名前の種類が 2 以上）、前年度の合計が正であること（例: FY2026 の先端半導体・人工知能関連技術勘定）。 |
| `一括計上` | 次をすべて満たす項（例: 国際観光旅客税財源観光振興推進費）。目が括弧書きのものだけである。前年度予算額が 0 で、要求額が正。予算書に同じ項がない（突合の状態が `NO_CANDIDATE`。予算書の無い年度は、この条件を問わない）。予備費・予備経費ではない。 |

## 項の範囲

- 範囲は、明細表の CSV の項の行（`CODE3`）から、次の項の行までとする。
- **項の行と見なすのは、`kou.csv` にある項だけ。** キーは、書（分冊の連番を除いた slug）＋項コード＋項名。内閣府などは、事項にも 3 桁のコードが付くため。
- **組織の見出し:** `kou.csv` にある組織の名前で、直後の行が項の行である `CODE3`。名前が組織でない行は、直後が項の行でも事項とする（例: FY2027 国土交通省の「075 経済安全保障の強化のための船舶のサプライチェーンの強靱化」は、項の範囲の最後の事項）。
- **特別会計・勘定の行（`CODE2` / `CODE1`）で範囲を区切るのは、直前の見出し（`CONTEXT`）が特別会計の書だけ。** 一般会計の書では、2 桁・1 桁の行は事項の番号になる（例: 文部科学省の「02 産業教育総合推進事業」）。

## 「事項要求」の出現を行に結びつける規則

plain text の行に「事項要求」（空白を除いて照合）があれば、1 回の出現とする。

- 同じ頁で直前（12 行以内）にある明細表の行に結びつける。
- その行が項の範囲にあれば、その項の出現とする。
- 組織の行に付いたものは、`orgs`（下）と `marks.csv` に出す。行に結びつかないもの（明細表以外の説明の頁や、事項名の中の括弧書きなど）は、`marks.csv` にだけ出す。

## 出力

**`kou.csv`**（形を 1 つ以上持つ項。同じ項が複数の書に載るときは 1 行）

| 列 | 内容 |
|---|---|
| `年度` `会計区分` `所管` `特別会計` `勘定` `組織` `項名` `項コード` | 項の識別 |
| `前年度予算額_千円` `要求額_千円` | `kou.csv`（項の年度推移）の値 |
| `MOF当初額_千円(参考)` | 突合の MATCHED / NEAR_NAME の予算書の額。同じ項が複数の行に対応するときは最初の行 |
| `MOFとの比較(参考)` | `当初>要求` / `当初=要求` / `当初<要求` / `MOFに対応なし`。FY2027 は空 |
| `形` | 上の表の形 |
| `印の行の階層` | 「事項要求」が付いた行の階層（項・事項・目など） |
| `根拠の行` | 最初の出現の行の本文 |
| `要求書` `頁` `PDF頁` | 要求書は、載っている書を空白で区切る。PDF頁は `kou.csv`（項の年度推移）の値で、空のことがある |

**`marks.csv`:** 「事項要求」の出現ごとに 1 行。列は、年度、要求書、PDF頁（plain text の頁）、行、種類（印・文）、階層、行の名前、項名（結びついた項）、本文。

**`summary.json`:** 年度ごとの出現数、項に結びついた数、組織の行の数、組織の数、結びつかない数、形ごとの項の数。

**`jikou.json.gz`（画面用）**

- 形: `{ years: { "2026": [[キー, 形の配列, 根拠の行], …] }, orgs: { "2026": [[組織のキー, 備考の本文], …] } }`（型は `BudgetRequestJikouData`）。`gzip` は level 9、mtime 0。
- キーは `会計区分(0|1)|所管（特別会計は特別会計名）|勘定|組織|項名`（項の年度推移の画面用 JSON の行と同じ並び）。組織のキーは項名を除いたもの。
- **画面に出すのは、備考に事項要求の記載がある項（`印`・`文`）だけ。** `要求0` と `一括計上` は CSV にだけ残す。`要求0` には、前年度限りの経費、施設費・船舶建造費の終了、移管、編成で額が付くものが混ざる。事項要求とは言えない。`一括計上` は、額を示している。
- **組織の行の事項要求（`orgs`）:** 組織の行の備考に事項要求があるもの。組織全体の方針として書かれ、どの項に含まれるかは要求書に書かれていない。項には割り振らない。備考の本文は、組織の行から次の明細表の行まで（同じ頁、10 行まで）の、印の桁より右の文字。組織の行は、先頭の「コード 組織名 前年度 要求 増減」を除く。10 行・頁の終わりで切れたものは末尾に「…」。
- 移管・改称で前の項をつないだ行は、つなぐ前の年度の項のキーが異なるため、その年度には付かない。

- `kou.csv` は 405 行。`要求0` の項（場所ごとを含む）の `MOFとの比較` は、FY2023〜FY2026 で `当初=要求` が 20 / 19 / 14 / 16、`当初>要求` が 10 / 11 / 12 / 12、`MOFに対応なし` が 1 / 1 / 1 / 0。
- 画面用 JSON の `years` の件数は 67 / 67 / 53 / 44 / 35、`orgs` は上の組織と同じ 12 / 6 / 6 / 7 / 11（合計 42 組）。
- `形のある項` は、場所と項名ごとにまとめた数（同じ項が複数の書に載れば 1）。形の列の数は、形ごとの項の数。

## 具体例

FY2026 の `kou.csv` の 1 行: 一般会計、所管 内閣府、組織 内閣本府、項名 内閣本府共通費（項コード 010）、前年度予算額 29,355,784、要求額 31,451,521（千円）、MOF 当初額 29,729,996（`当初<要求`）、形 `印`、印の行の階層 `項`、根拠の行 `010 内 閣 本 府 共 通 費 （事項要求）`（空白は plain text の字間のまま）、要求書 `cao.go.jp__yosan__soshiki__r08__pdf__00`、頁 2。項の見出しの行に印が付いており、項の額の全体が事項要求というわけではない。
