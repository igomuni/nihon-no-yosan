# RS システムのデータ品質：入力システムの面から見た手がかり（第 1 段）

作成日: 2026-11-04（日本時間）
状態: 作業メモ。原因や補正の判断は付けていない。「推測」と書いたものは、データだけでは確かめられていない。
対象: `data/download/rs/2025/` の 15 ファイル（RS 2025 年度版。全 10,694,080 セル）。法人番号と名前の照合には、旧リポジトリの `houjin.db`（国税庁の法人番号データ。`updated_at` の最大が 2026-01-30。読み取りだけ）を使った。
前の段: `20261104_1800_RS_CSV_列の洗い出し.md`

## 見方

現場から「入力システムが使いにくい」という声がある。データから、システムの側の欠陥（検証の欠け、マスタ参照の欠け、必須欄の回避、出力の不整合）を示す手がかりを探した。RS のサイトの「データに関する留意事項」（旧リポジトリ `docs/` に保存）には、次の趣旨がある。

- 検索・分析の対象は、「事業所管課室」「政策・施策」「歳出予算項目」はマスタから入力されたもの、「支出先名」は法人番号が入力されたものに限られる。
- 2021〜2023 年度は移行データ（百万円を機械的に 1,000 倍している、など）。

つまり、欄は「マスタから選ぶ欄」と「自由に入力する欄」に分かれる。自由入力の欄ほど、ばらつきが出やすい。

## 結果

### A. 法人番号（5-1・5-3・5-4。名前のある行 210,450 行）

| 区分 | 行数 |
|---|---|
| 名前が法人番号 DB の名前と一致（幅・空白・法人格の違いを除く） | 160,914 |
| 名前が部分一致（支店名・部署名など） | 3,450 |
| 名前が不一致 | 5,867 |
| 法人番号なし（空、または 9 だけ） | 40,059 |
| 検査用数字が合わない | 147 |
| 検査用数字は合うが DB に無い | 13 |

- 不一致の中身は、金額の上位 300 組だけ分けて見た（全体は未分類）。国・地方公共団体の番号（国土交通省の番号に地方整備局の名前が付く、など）が 145 組、法人の番号が 155 組。
- 法人の 155 組は、名前の似かたで分けた。似ている（類似度 0.8 以上）45 組、中間 35 組、似ていない（0.5 未満）75 組。
  - 似ている例: 「東京電力エネジーパートナー」（DB は「エナジー」）、「国立研究開発法人新エネルギー・産業技術研究機構」。入力ミスの可能性が高い。
  - 似ていない例には、法人の改称が混ざる（「エヌ・ティ・ティ・コミュニケーションズ」→ DB は「ＮＴＴドコモビジネス」、「東日本電信電話」→「ＮＴＴ東日本」）。DB が 2026-01 時点なので、時点の差。入力ミスではない（推測）。
  - 番号の取り違えが疑われる例: 「富士ソフト株式会社」の番号が、DB では別の会社。
  - **支出先名の欄に、契約名・業務名が入っている例**がある（「補助金執行」「プロジェクトマネジメント業務」に、別の法人の番号が付く）。欄の取り違えの可能性（推測）。
- 支出先名に、業務名・経費名らしい語（旅費・間接経費など）があり、組織名らしい語がない行が 627 行（法人番号なし 565 行）。ヒューリスティックで、誤りと決めたものではない。
- 法人番号が入力されていない支出先は、サイトの検索・分析の対象外（公式の留意事項）。法人番号が空や 9 だけの行が 40,059 行ある。
- 検査用数字が合わない番号は 147 行・50 種類。末尾に 0 が並ぶ番号（14 行）、見本の番号 `1234567890123`（6 行）、桁の入れ違いらしいもの（127 行）。
- **手がかり（推測）:** 法人番号の入力に、検査用数字の検証がない。法人番号と名前の照合（マスタ参照）もない。番号が分からないときに 9 や 0 で埋められる。

### B. 計算欄は整合している

- 5-1: 支出先の合計 = 契約の金額の合計（73,914 組で全件一致、不一致 0）。ブロックの合計 = 支出先の合計の和（19,125 ブロックで全件一致、不一致 0）。
- 2-1: 歳出予算現額 = 当初 + 補正 + 前年度繰越 + 予備費等（23,036 行で全件一致）。執行率は、執行額 ÷ 現額と一致が 15,349 行、±0.6 ポイントを超える不一致が 46 行。
- 数値でない値、5-1 の小数は 0。負の値は、金額で 32 行、支出先の合計で 2 行。
- **手がかり（推測）:** 合計欄は、システムが計算している。手入力の合計の食い違いは見つからなかった。

### C. 2-1 の行は 2 種類に分かれる

- 「合計」の列（当初予算(合計) など）が入る行が 23,036 行、会計別の列が入る行が 24,064 行。両方が入る行は 0。
- 行ごとに入る列が違うので、使うときは区別が要る（`rs-tab.md` は合計の行を使っている）。

### D. CSV の文字は出力前に正規化されている

- 全 10,694,080 セルのうち、NFKC で変わるセルは **0**。全角英数字、全角かっこ、全角スペース、半角カナ、機種依存文字（① ㈱ ㎡）は 0。改行を含むセル、前後の空白、連続する空白、文字化けも 0。外字（私用領域）は 5 セル。
- つまり、RS のシステムか CSV の出力で、NFKC 相当の変換と改行の除去がされている（どの段かは確かめていない。推測）。
- **影響:** 説明文の「改行・箇条書きの入力形式の違い」は、CSV からは見えない。① が 1 になるなど、元の字形の情報も失われている。入力の実態を見るには、元のレビューシート（サイトのシートや各府省のシート）が要る。
- 改行がなくても、記号は残る（30 字以上のセルでの出現セル数）: 中黒（・）170,300、半角かっこ 171,866、コロン 45,445、「」 39,899、※ 14,534、(1) 形式 2,121、◆◇●○■□ 1,409、「数字+.」 560。

### E. 空欄の埋め方

- 「-」7,406、「ー」4,873、「なし」429、「---」158、「特になし」60、「該当なし」51、「無し」25、「N/A」22。
- 同じ列に「-」と「ー」が混ざる（3-1 活動指標/成果指標: 「-」2,132、「ー」1,848）。
- **手がかり（推測）:** 必須の欄に、何かを入れないと進めない作りで、利用者が記号で埋めている。

### F. 府省庁の列：5-2 だけが違う

- 416 事業で、5-2 の「府省庁」だけが、ほかの 14 ファイルと違う。5-2 は外局を親の府省で出す（水産庁→農林水産省 75、観光庁→国土交通省 70、文化庁→文部科学省 66、スポーツ庁→文部科学省 51、林野庁→農林水産省 44、特許庁→経済産業省 34、消防庁→総務省 25 など）。
- 5-2 の「府省庁」が空の行が 236 行（全 23,381 行）。
- 事業名は、全ファイルで事業 ID ごとに一致している（5,794 事業すべて）。

### G. 文字化けはなく、貼り付けの跡がある

- 文字化けを示す代用文字（U+FFFD）、Latin-1 などの誤読の特徴、制御文字は、どれも 0 件。日本語の間の「?」15 セルは、文末の疑問符（元は「？」）。
- **ゼロ幅スペース（U+200B）: 231 セル**（見えない文字。NFKC では消えない）。大半は説明文の列（3-1 のアクティビティ/活動目標/成果目標 55、活動指標/成果指標 28、1-2 の事業の概要 27 など）。名前の列では、事業名に含む事業が 1 件だけ（15 ファイルすべてで同じ名前）。支出先名・契約先名には無い。
- **私用領域の文字: 5 セル**（U+F06C、U+F0A7）。1-2・2-1・4-1 の文頭。Word の箇条書き記号（Symbol / Wingdings）が貼り付けられた跡（推測）。
- 「■」34 セルは、見出しとして意図した使い方。
- **手がかり（推測）:** 入力欄が、貼り付けた文字を検査せずに受けている。

### H. 事業名は事業を決められない

- ゼロ幅スペースを除くと事業名が同じになる、別の予算事業 ID の組が 65 組ある（例: 「健康・医療戦略の推進に必要な経費」ID 292 と 34、「社会資本整備総合交付金」ID 178 と 4447）。府省庁が違うのか、新旧の ID なのかは、確かめていない。
- 事業名は、全ファイルで事業 ID ごとに一致する（5,794 事業すべて）。

### I. 真偽値の表記がファイルで違う

- 5-1 の「その他支出先」「その他の契約」は `TRUE` / `FALSE`、5-4 の「その他の契約」は `t` / `f`、5-2 の「担当組織からの支出」は `TRUE` / `FALSE`。
- **手がかり（推測）:** 出力の処理が、ファイルごとに別（真偽値の文字列化が統一されていない）。

## 洗い出しの限界

- 法人番号 DB は 2026-01 時点。改称・合併による差を入力ミスと区別できない。
- 不一致の分類は、金額上位 300 組だけ。
- 金額の合計は出していない（5-x の金額には、間接支出の重複が含まれうるため、合算が意味を持つか未確認）。
- 説明文の誤字・入力形式は、CSV に改行がないため、洗い出せていない。
- 文字の検査は 2025 年度版だけ。2024 年度版との比較はしていない。
