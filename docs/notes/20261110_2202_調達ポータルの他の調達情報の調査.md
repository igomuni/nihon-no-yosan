# 調達ポータルの他の調達情報の調査

作成日: 2026-11-10（日本時間）
状態: （作業メモ。結論や承認ではないことなど、1〜2 行で書く）

調達ポータルで、落札実績のほかに、一括で取れる調達情報があるかを調べた。結論: 見つからなかった（落札実績だけ）。確かめた日: 2026-11-10。

## 読んだページ（調達ポータル）

- トップ、サイトマップ、本システムについて、関連サイトへのリンク、操作マニュアルの一覧、調達情報検索（`UAA01/OAA0100?OAA0115`）、事業者情報検索（`UAB01/OAB0101`）。
- 「ダウンロード」「オープンデータ」の語があるのは、落札実績情報のダウンロードだけ。
- 調達情報検索は、画面の検索のみ。ページに「検索結果を表示できる件数は最大500件」とある。CSV の出力は、見当たらない。
- 事業者情報検索も、画面の検索のみ。
- 入札結果確認・契約業務などは、ログインが要ると見られるが、ログイン画面は見ていない（未確認）。

## e-Gov API カタログ

- 「調達情報等公開機能」（デジタル庁、調達総合情報システム）: 「統一資格者情報（CSV、XML）、及び調達情報（CSV）を提供するAPI」とある。公開 URL は `chotatujoho.geps.go.jp/va/com/information_m.html`。
- その URL は、調達ポータルへの転送ページだった（旧 GEPS のポータルが統合された）。カタログの記載は古い可能性が高い。落札実績のダウンロードと同じものかは、未確認。

## 調達ポータルの外（検索結果で見えた範囲。ページ本文は読んでいない）

- data.go.jp に、府省ごとの契約情報がある（防衛省の随意契約・XLS・CC BY、文部科学省の過去の随意契約など）。政府全体を横断する CSV は、見つからなかった。
- JETRO の政府公共調達データベースは、官報の公告・公示の原文を載せる。一括取得できるか、利用条件は、未確認。

## RS との関係（推測）

- RS の CSV に、契約・支出先のデータセット（`contracts` など）がある。調達の別の入手経路を探すより、RS の契約の中身を見るほうが早いかもしれない。中身（入札方式・落札率の有無）は、今回は確かめていない。
