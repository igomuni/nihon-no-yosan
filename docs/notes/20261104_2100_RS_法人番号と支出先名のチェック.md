# 法人番号と支出先名のチェック（RS 5-1・5-3・5-4）

作成日: 2026-11-04（日本時間）
状態: 作業メモ。チェックの案と、2025 年度版で試した結果。結論や運用の承認ではない。
対象: `data/download/rs/2025/` の 5-1（支出情報）・5-3（費目・使途）・5-4（国庫債務負担行為等による契約）の、名前のある 210,450 行。法人番号と名前の照合には、旧リポジトリの `houjin.db`（国税庁の法人番号データ。`updated_at` の最大が 2026-01-30。読み取りだけ）を使った。
関連: `20261104_1930_RS_データ品質_システム面の手がかり.md`（全体の手がかり）

## 目的

RS の支出先を、法人番号でまとめられるか。法人番号と支出先名の食い違いから、入力の誤りを検出できるか。

## チェックの 3 段

1. **検査用数字の検算:** 法人番号 13 桁の先頭 1 桁は検査用数字。残りの 12 桁から計算した値と合わない番号は、誤りと確定できる（国税庁の方式）。
2. **DB の名前との照合:** 番号から DB の法人名を引き、書かれた名前と比べる。比べる前に、幅（NFKC）、空白、法人格（株式会社など）、中黒、長音・ハイフン、かっこ・記号を揃える。
3. **名前から番号の候補を探す:** 1・2 で問題のある行について、名前で DB を引き、同名の法人番号を候補にする。候補が複数なら、RS の所在地が DB の都道府県・市区町村を含むかで絞る。RS の別の行で、同じ名前が DB と整合する番号と一緒に出ていれば、それも候補にする。

## 機能する点

名前と法人番号の組 20,633 組（170,231 行）の照合結果。

| 区分 | 組 | 行 |
|---|---|---|
| そのまま一致 | 16,498 | 143,221 |
| 幅（全角/半角）を揃えると一致 | 1,998 | 16,272 |
| 法人格を揃えると一致 | 387 | 1,180 |
| 長音・ハイフン / 中黒 / 空白 / かっこ・記号を揃えると一致 | 75 / 23 / 14 / 2 | 247 / 73 / 46 / 4 |
| どれでも一致しない | 1,636 | 9,188 |

- **検査用数字の検算は、確実に働く。** 合わない番号は 147 行（50 種類）。13 桁でない番号、数字以外の文字を含む番号は 0。
- **名前の違いの大半は、揃えれば解決する。** 最大は幅の違い（1,998 組）。RS の CSV は NFKC で正規化済み、DB は全角のままなので、入力ミスではなく比べ方の問題。
- **検査用数字エラーは、名前から結べるものが多い。** 53 組のうち 37 組（70%、108 行）は、同名の候補が 1 件に決まる。うち 25 組（76 行）は、候補の番号と書かれた番号が 1〜2 桁違い、または隣の桁の入れ替えで、入力ミスと整合する。
- RS の中でも結べる。同じ名前で DB と整合する番号が別の行にあるのは、検査用数字エラーで 36 組（103 行）、名前不一致で 48 組（127 行）、番号なしで 159 組（689 行）。

## 課題と具体例

### 1. 改称と入力ミスを区別できない

DB の名前は 2026-01 時点。その後に改称した法人も、RS が書いた旧名と不一致になる。
- 「エヌ・ティ・ティ・コミュニケーションズ株式会社」（527 行）は、DB では「ＮＴＴドコモビジネス株式会社」。
- 「東日本電信電話株式会社」（272 行）は、DB では「ＮＴＴ東日本株式会社」。
- 「日立GEニュークリア・エナジー株式会社」は、DB では「日立ＧＥベルノバニュークリアエナジー株式会社」。

### 2. 国・地方公共団体の番号に、下部組織の名前が付く（仕様どおり）

- 国土交通省の番号 `2000012100001` に、関東地方整備局、東北地方整備局など 81 の名前が付く。
- 番号を見ると誤りに見えるが、誤りではない。照合から除く必要がある（国・地方公共団体の番号は、桁の並びで判別できる）。

### 3. 番号なしの行は、名前でも結べない

- 番号なし（空、または 9 だけ）は 6,851 組（40,059 行）。名前で候補が 1 件に決まるのは 243 組（944 行、行の 2.4%）だけ。候補なしが 6,512 組（行の 97%）。
- 中身は、個人、「その他」「期間業務職員」などの集計の名前が多い。名前でも結べないものは、そのまま残す。

### 4. 同名の別の法人と区別できない

- 同じ名前に複数の番号が付く。「日本電気株式会社」は 3 種類（7010401022916 が 1,135 行、6010601062093 が 3 行、6120001240354 が 8 行）。「株式会社マクロミル」は 2 種類（9010001157227 が 25 行、8010001157236 が 22 行）。
- 名前が同じでも、別の法人か、番号の誤りかは、データだけでは決められない。
- DB で同名が 1 件でも、その法人だとは限らない。

### 5. 桁がずれた誤記は、1〜2 桁違いの判定に入らない

- 「宮城県森林組合連合会」`4437000500160` と、候補 `4370005001606`。
- 「国立研究開発法人日本医療研究開発機構」`9010000502379` と、候補 `9010005023796`。
- 検査用数字を落として書いた、またはずらして書いたように見える（推測）。「入力ミスと整合」の数え方には入っていない。

### 6. 名前の欄に、契約名や業務名が入る

- 「補助金執行」（3 行、約 268 億円）に、別の法人（公益財団法人）の番号が付く。
- 「プロジェクトマネジメント業務」に、別の法人（国立研究開発法人）の番号が付く。
- 欄の取り違えの可能性（推測）。名前から番号を探しても、結べない（候補なし 294 組の一部）。

### 7. 他社の番号を書いた取り違えが疑われる

- 名前不一致で、候補が 1 件に決まる 80 組のうち 77 組は、番号が大きく違う。
- 「富士ソフト株式会社」は、番号 `2020001043507` が DB では別の会社の番号で、名前から出る候補は `2010001246985`。

### 8. 誤字・表記の違いが、別のものに見える

- 同じ番号で名前が違う例: 「ビックローブ株式会社」と「ビッグローブ株式会社」、「アクセンチュア株会社」と「アクセンチュア株式会社」、「東京電力エネジーパートナー株式会社」と DB の「エナジー」。
- 法人の種類そのものが違うものも、法人格を揃える段で一致扱いになる（「公益財団法人経済同友会」と「公益社団法人経済同友会」）。別の法人か入力ミスかは、別に確かめる必要がある。

### 9. 共同企業体に構成員の番号が付く

- 「戸田・西松・大城・屋部共同企業体」（10 行、約 370 億円）の番号が、DB では「戸田建設株式会社」。

### 10. 見本や埋め草の番号

- `1234567890123`（6 行。「アフリカ各国PKO訓練センター」）。
- 末尾に 0 が並ぶ番号（14 行）。「ジェーアイシー旅行センター株式会社」の `9011100000000` は、候補 `9011101023772` とほぼ同じ書き出し。
- 番号が分からないときに、何かを埋められる作りに見える（推測）。

## 限界

- 候補は名前の一致だけで、正しいことの確認ではない。
- DB は 2026-01 時点で、閉鎖・合併の状況は見ていない。
- 名前不一致 405 組のうち、候補なしの 294 組は、改称・誤字・欄の取り違えのどれかを区別していない。
- 補正は、元の値を書き換えず、辞書として別に持つ方針。この表の数字は、辞書に入れる候補の見積もり。
- 国税庁の `houjin.db` の元データの利用条件は、基本3情報の全件ダウンロードの規約を読んでいない。結果を公開するときは、先に読む。
