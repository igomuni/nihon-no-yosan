# 立ち上げと移行の順番

状態: 1 が完了（骨組み・CI・ドキュメントの規則・名前の揃え方）。2 は、純粋な関数の移動まで済み（下）。3 は、凍結と manifest まで済み（PR で確認）。4 は、build をすべて移し、前のリポジトリの出力とのバイト一致まで済み（下）。5 は、2 画面を移し済み（下）。次は、基準データの公開（Releases）か、6。

1. 骨組み: workspaces・TypeScript・lint・テスト・CI、ドキュメントの規則、決めたこと（0001〜0003）。core の最初の関数として名前の揃え方。
2. core に、前のリポジトリ（marumie-rssystem）の純粋な関数を移す: 項・事項・目の鍵、名前でつなぐ処理、概算要求と予算書の突合の規則。テストも一緒に。
   - 済み: CSV と金額の読み方、概算要求書の木（目次・総表の小計の構造・位置の木）、明細表の項の範囲と目、予算書の額の列と項の鍵、`pairByName`、目のコード。前のリポジトリの fixtures の全件で、前の lib と出力が一致することを確かめた。
   - 4 に回す: 突合 M0〜M3 の組み立て（主体の対応、文書セット、項名の対応表、`NEAR_NAME`・`ZERO_AMOUNT`）。前のリポジトリでは build のスクリプトの中にあり、出力のバイト一致で確かめながら移す。
   - 5 に回す: 画面の行のキー（`mofRowKey`・`jikouKeyOf`）。画面のデータの型に依存する。
   - 移さない: `mof-keys`（V2 の予算書の正規化）と `match-key`（V1 の RS とのつなぎ）。0001 で V1・V2 を持ち込まないため。
3. 基準データ（原本の形の CSV）の初版を作る。manifest に SHA-256。利用条件を確かめるまで非公開。
   - 済み: `docs/guides/data.md` の「基準データの初版」。681 書、2,298 ファイル、283 MB。手元の `data/dataset/reference-v0/` と `datasets/reference-v0/manifest.json`。

   - 済み: 公開（Releases）。公開できる 671 書の分を `dataset-reference-v0` に置いた（`docs/guides/web-publish.md`）。
   - 残り: 会計検査院と裁判官訴追委員会のサイトが応答せず、本文が未読（その 10 書は、読むまで公開しない）。
