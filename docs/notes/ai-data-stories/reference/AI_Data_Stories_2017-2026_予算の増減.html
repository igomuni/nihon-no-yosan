04 / HOW TO READ THIS

この数字から言えること、言えないこと。

確認できたこと

一般会計の当初予算相当額は2017年度の97.455兆円から2026年度の122.309兆円へ増えました。所管別にみると財務省・総務省・厚生労働省・防衛省の増加が大きく、同一名称の「項」では国債費・地方交付税交付金が増えています。

一方、「社会資本総合整備事業費」「復興事業費等東日本大震災復興特別会計へ繰入」「恩給費」など、同一名称で縮小した項目も確認できます。

この分析だけでは言えないこと

予算の実質購買力、決算での執行額、国と地方を合算した支出、社会保障やインフラなど政策分野全体の増減までは確定できません。また、名目の「項名」が一致することは、会計上の定義が10年間完全に一致する保証ではありません。

特別会計を単純合算すると一般会計からの繰入などを二重計上し得るため、このLPの増減額には含めていません。

AI DATA STORIES / EVIDENCE

データと分析方法

データ：ユーザー提供の mof-history-v0.tar.gz の mof-archive/2017〜2022/kou-general.csv、reference-v0.tar.gz の mof-archive/2023〜2026/kou-general.csv を使用しました。データ列は「○年度要求額(千円)の合計」（2024年度は列名の単位表記が省略）。金額は千円から兆円へ換算し、項名で集約しています。これはプロジェクトが原資料を抽出した加工データです。国の公表原本そのものの完全性を保証するものではありません。

方法：年度別合計は「項」の行を合算。所管別の増減は同一所管名の合計差。「項」単位の増減は両年に出現する項名の完全一致による比較です。未出現年度は欠損（null）として扱い、ゼロで補完していません。金額は名目額で、補正予算・決算・特別会計を含みません。出典行番号はCSVヘッダーを1行とする1始まりの行番号です。

個別予算の出典：項目をクリックした詳細画面に、原データのファイルパス、行番号、所管・組織・項コードを表示しています。グラフと数値は元CSVを元に本LPで計算したもので、政府による集計結果ではありません。
