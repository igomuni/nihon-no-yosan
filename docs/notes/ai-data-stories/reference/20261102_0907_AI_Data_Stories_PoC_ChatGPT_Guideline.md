# AI Data Stories — ChatGPT PoC用ガイドライン

作成日：2026-11-02（日本時間）  
状態：初回体験検証用ドラフト。実装・一般公開を承認するものではありません。

## 目的

日本の公的な予算関連資料に由来するデータを材料に、利用者の関心を引き出し、データの発見を伝える個別のLP（ランディングページ）を生成し、その後の対話を通じて問いや意見を深められるかを検証します。

## 新しいChatGPTチャットで使う指示文

以下のデータは、日本の公的な予算関連資料をもとに、`nihon-no-yosan` プロジェクトが抽出・構造化したものです。添付したデータ全体を探索対象として、私の関心を引き出しながら、私だけの情報探索LPを作ってください。

**進め方**

1. まず添付ファイルの形式、収録内容、年度、データの探索可能範囲を確認してください。全件にアクセスできたか、読めなかったものがないかも明示してください。
2. 私の関心が曖昧であれば、自然なインタビューを通じてテーマを一緒に発見してください。最初から調べたいことが明確なら、不要な質問を挟まず分析に進んでください。
3. テーマが定まったら、添付データから関連情報を探し、必要に応じて検索・集計・比較を行ってください。データ全体を一度に文章として読み込む必要はありません。
4. データで確認できた発見を中心に、図表や説明を含む個別のLPをHTMLで生成してください。LPの構成、デザイン、可視化方法は自由に考えてください。
5. LPの生成で終わらず、私の意見や新たな疑問を引き出し、次の探索につなげてください。

**守ってほしいこと**

- 最初の検証では、添付データだけを根拠にしてください。外部Web検索による補完は、私が明示的に許可するまで行わないでください。
- 数値を示す際は、確認できる範囲で年度、金額の単位、予算・決算・概算要求等の区別、出典を示してください。
- 公的機関の原資料、プロジェクトが行った抽出・正規化・構造化、AIによる計算・解釈を区別してください。加工データを政府が保証した原本として扱わないでください。
- 空欄・欠損をゼロとみなしたり、根拠のない項目間の対応関係を確定したりしないでください。確認できない点は未確認・未解決として示してください。
- ファイルが読み込めない、一部しか探索できない、根拠が不足している場合は、その制約を率直に説明してください。探索できていないデータまで調べたと主張しないでください。
- LPの見た目だけでなく、根拠を利用者が追跡できることを大切にしてください。

質問の順序やLPのデザインを私に細かく決めさせるのではなく、必要な質問をしながら進めてください。

## PoCで観察したいこと

- 全量のCSV・JSON・TXTを含む既存データアーカイブを、どの範囲まで探索できたか。
- 漠然とした関心と、明確な調査目的の両方に対応できるか。
- LPに示した数値・出典・データの意味が検証可能か。
- LPをきっかけに新たな問いや利用者自身の意見が生まれるか。

## この段階で固定しないこと

インタビューの定型台本、LPのレイアウト、特定テーマへの事前限定、SQLite等へのデータ変換、Git上のハーネス構築は、初回PoCの前提条件にしません。データパックの再配布や外部AIへのアップロードに関する利用条件・権利確認は、一般公開判断とは別に扱います。
