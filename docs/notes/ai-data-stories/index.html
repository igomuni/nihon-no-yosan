国の予算を、問いで読む

財務省の予算書・決算書、各府省の概算要求書、行政事業レビューのデータを、このプロジェクトで構造化したものだけを根拠にしています。各回の数字には、原資料・加工・AI の計算のどれに当たるかを付けています。

  1. 0予算の10年 この10年で、何が増えて、何が減ったか（一般会計の当初予算、FY2017→FY2026） 97.5兆円 → 122.3兆円（+24.9兆円）。増加の 86% は国債費・地方交付税・防衛など 6 つの経費
  2. 1予算の一生 当初予算は、補正・予備費・繰越を経て、いくら使われ、いくら残ったか（FY2017〜FY2024） FY2020 は当初 102.7兆円が補正で現額 182.3兆円に。支出 147.6兆円、繰越 30.8兆円、不用 3.9兆円
  3. 2要求と政府案の差 各府省の概算要求は、政府案でどれだけ削られ、どれだけ増えたか（FY2023〜FY2027） 4 年とも政府案が要求を上回る（FY2023 +4.06兆円、FY2026 +2.60兆円）。国債費は毎年、要求より少ない
  4. 3子育て予算の引っ越し こども家庭庁と子ども・子育て支援特別会計の新設で、お金の流れはどう組み替わったか FY2023 のこども家庭庁 3.97兆円のうち 98% を、前年の内閣府・厚生労働省などの目に照らせた（候補）
  5. 4防衛費の中身 防衛関係費の増加は、装備品・施設・人件費の何に向かったか 5.1兆円 → 9.0兆円。増加の 82% は物件費（航空機修理費は 0.34 → 1.02兆円）
  6. 5AI と人工知能 予算書の「人工知能」と、行政事業レビューの「AI」は、事業の単位でどこまでつながるか 予算書の名前に「AI」は 0 件、RS の事業名は 36 件。FY2025 の 39 事業のうち 27 が予算書の項に結べた

2 回目: 深掘りと新しい問い

  1. 6予備費の行方 コロナ等の予備費は、決算でどこに、いくら使われたか（FY2017〜FY2024） 8 年で計上 33.7兆円、使用 26.0兆円。85% が FY2020〜FY2022。ウクライナ予備費は 2 年とも使用 0 円
  2. 7国債費の中身 国債費の増加は、償還か利払いか。国債整理基金特別会計の側で何が起きているか +7.75兆円のうち利払いの見込みが +3.90兆円。実際に払った利子は 8.9兆円前後で横ばい（FY2024 まで）
  3. 8使い切れない予算 翌年度繰越と不用は、どの項で生まれ、繰越はどこへ行ったか FY2020 の繰越は 30.8兆円（現額の 16.9%）。内閣府の繰越の 82.5% は地方創生臨時交付金の 2 項
  4. 9人件費の10年 国の人件費は、どの府省・どの費目で増えたか 4.39兆円 → 4.88兆円（+11.3%）。一般会計に占める割合は 4.50% → 3.99%。増加の 51% は防衛省
  5. 10特別会計の地図 特別会計の規模と、会計間の繰入を除いた純計はどれくらいか 一般会計と足した 564.0兆円のうち 158.6兆円（28%）は会計間の繰入。試算純計は 405.4兆円

3 回目: お金の通り道を追う

  1. 11交付金の行方 地方創生臨時交付金は、補正・予備費・移し替え・繰越を経て、どこでいくら支出されたか 入り 22.75兆円、支出 18.22兆円、不用 3.30兆円。内閣府の項からの支出は 5 年間 0 円で、払うのは総務省
  2. 12補正予算の10年 補正予算は、毎年なにに足され、なにから減らされてきたか 10 年で差し引き 197.7兆円。コロナ後も年 13〜18兆円で、コロナ前の 4〜5 倍が続く
  3. 13地方へ渡るお金 国の予算のうち、地方に渡るお金はどれくらいで、どう変わったか 33.9兆円 → 41.8兆円（+7.9兆円）。増加の 45% は地方交付税。補助負担金はほぼ横ばいで中身が入れ替わる
  4. 14財政投融資の山 FY2021 に膨らんだ財政投融資特別会計は、どこまで使われたか 当初 72.6兆円 → 補正後 40.5兆円 → 支出 35.3兆円（当初の 49%）。使わなかった分は繰り越さず不用
  5. 15お金の行き先 国の事業のお金は、どの種類の相手に、何段で流れたか（行政事業レビュー、FY2024 の執行） 直接払った 126.9兆円の 39.6% は年金などの受給者。2 段目以降の支出先がある事業は 39.2%

4 回目: 仕組みの形を見る

  1. 16移し替えの地図 予算を持つ府省と、実際に払う府省は、どれだけ違うか（予算決定後の移し替え） 8 年で 11.32兆円。その 95.9% は地方創生臨時交付金の内閣府 → 総務省。一括計上は決算の移し替えにほぼ出ない
  2. 17基金へのお金 基金・出資金・資金へのお金は、当初と補正のどちらから、どの府省から出ているか 10 年で 29.26兆円、その 80% は補正予算から。当初で毎年積む基金は科研費が中心
  3. 18契約の方式と入札 国の事業のお金は、どの契約方式で払われたか（行政事業レビュー、FY2024 の執行） 支払いの 3.8% が調達。一般競争の契約の 48.5% は入札者が 1 者（件数）
  4. 19障害福祉の10年 障害福祉の予算は、10 年でどれだけ、どの給付で伸びたか 1.73兆円 → 2.93兆円（+68.8%）。一般会計の伸びの約 2.7 倍で、10 年間毎年増加
  5. 20特別会計の使い残し 特別会計は、使えるお金のうちどれだけを使い残したか 8 年の不用は 152.2兆円（4.5%）で一般会計の約 4 倍。繰越は約 3 分の 1

5 回目: 見積もりと実際

  1. 21年金の見積もりと実績 年金特別会計の給付は、見積もり（当初予算）と実績がどれだけ離れているか 基礎年金給付費の不用は 0.87兆円 → 4.56兆円（FY2024）。当初に対する支出は 96.3% → 84.8%
  2. 22防衛の契約 防衛省は、何を、どんな契約方式で買っているか（行政事業レビュー、FY2024 の執行） 最大は航空機の 1.49兆円。航空機の調達の 59% は随意契約（その他）
  3. 23コロナ期の資金繰り コロナ期の企業の資金繰り支援（出資・保証・給付金）は、どこまで使われたか 入り 25.94兆円、支出 23.17兆円（89%）。公庫への出資の支出は 1 年遅れて FY2021 に山
  4. 24研究開発の基金 研究開発の基金は、積んだ後どう見えるか（予算書・決算・行政事業レビュー） 10 年で 3.82兆円、68% が補正。決算では積んだ年に全額支出済で、その先は見えない
  5. 25教育予算の10年 教育の予算は、10 年でどう動いたか。FY2026 の伸びの中身は何か 4.05兆円 → 4.60兆円（+13.6%）。増加の大半の +0.48兆円 は FY2026 の 1 年（高校就学支援・給食費）
