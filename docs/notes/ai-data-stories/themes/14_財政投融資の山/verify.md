# テーマ D「財政投融資の山」検算の記録（2026-11-03）

## 入力
- 予算書（当初）: `mof-archive/{年度}/kou-special.csv`・`moku-special.csv`。FY2017〜FY2022 は mof-history-v0、FY2023・FY2024・FY2026 は reference-v0、FY2025 は reference-v0 の `2025_teishutsu`（パイプラインの `LIFECYCLE_SOURCES` と同じ版）。
- 補正: `kou-special-hosei{,-2,-3}.csv`（回ごと）。補正後 = 補正の書に載る項は最後の回の改予定額、載らない項は当初。FY2026 は特別会計の補正の書が無い。
- 決算: `kou-special-kessan.csv`（FY2017〜FY2024）。
- 一般会計との受け渡し: 画面用 `apps/web/public/data/lifecycle/data.json.gz`（a3.ts）。

## スクリプト
- `a1.py`: 財投特会の項ごとの当初・前年度予算額・補正後・決算 → `a1.json`
- `a2.py`: 勘定別の合計、補正の回ごとの額、恒等式の検算 → `a2.json`
- `v1.ts`: 別の方法（lifecycle の events → `lifecycleValues`）で年度合計を出し、`a2.json` と比較
- `a3.ts`: 一般会計 ⇄ 財投特会の繰入 → `a3.json`
- `build.py` + `template.html` → `index.html`・`preview.html`・`page-data.json`
- `stub.mjs`: DOM の代用でスクリプトを走らせ、NaN・SVG のはみ出しを確認

## 検算の結果
| 項目 | 結果 |
|---|---|
| 決算の式 現額 = 歳出予算額 + 前年度繰越 + 予備費 + 予算総則 + 流用 + 移替 | FY2017〜FY2024 の全項で円まで一致（不一致 0） |
| 決算の式 現額 = 支出済 + 翌年度繰越 + 不用 | 同上 |
| 決算の歳出予算額 = 補正後（上の定義） | 全年度・全項で円まで一致。補正後の作り方の裏付け |
| 年度合計（当初・補正後・現額・支出・繰越・不用） | lifecycle（v1.ts）と CSV 直接（a2.py）が全年度で 1 円以内で一致（不一致 0） |
| FY2020 → FY2021 の当初の増加 | 25.082 → 72.624 兆円、+47.54 兆円（2 回目「特別会計の地図」の +47.5 と一致） |
| FY2023 防衛力強化一般会計へ繰入 | 財政融資資金勘定 2,000 億円 + 投資勘定 4,366.7 億円 = 0.637 兆円（特別会計の地図の 0.64 と一致） |
| FY2021 予算書の前年度予算額 54.2 兆円 | FY2020 の第 2 次補正後の改予定額 54.2 兆円と一致（第 3 次補正で 40.7 兆円） |
| FY2022〜FY2025 の前年度予算額 | 前年度の補正後と一致（15.0・16.5・5.0・9.5） |

## 主な数値（兆円）
- 財投特会 当初: FY2020 25.08 → FY2021 72.62。補正後 40.55、支出済 35.35（当初の 48.7%）、不用 5.20。
- 財政融資資金へ繰入: FY2020 当初 12.0 → 第1次 21.4 → 第2次 54.2 → 第3次 40.7、支出 39.08・不用 1.62。FY2021 当初 45.0 → 補正 15.0、支出 10.14・不用 4.86（当初の 22.5%）。FY2022 25.0 → 16.5 → 14.13。FY2023 12.0 → 5.0 → 3.00。
- 国債整理基金特別会計へ繰入: FY2020 当初 12.06 → FY2021 26.62（補正後 24.82、支出 24.78）→ FY2022 22.59（18.55、18.48）。
- 8 年度（FY2017〜FY2024）: 当初 280.2、補正後 253.1、支出 238.6、不用 14.7、翌年度繰越 0.11。
- 翌年度繰越は毎年 0.002〜0.040。
