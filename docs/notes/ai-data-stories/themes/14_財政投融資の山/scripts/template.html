FY2021 の 72.6兆円は、どこまで使われたか

財政投融資特別会計の当初予算は、FY2020 の 25.1兆円から FY2021 に 72.6兆円へ膨らみました。ところが、その年の補正で大きく減らされ、実際に支出したのは半分以下でした。

当初予算補正後支出済（決算）

膨らんだのは「財政融資資金へ繰入」と「国債整理基金特別会計へ繰入」

  • 勘定は 3 つ。お金のほとんどは財政融資資金勘定財政融資資金勘定・投資勘定・特定国有財産整備勘定のうち、財政融資資金勘定が毎年 95% を超えます。投資勘定（産業投資など）は当初で 0.67〜1.02兆円、特定国有財産整備勘定は 0.03兆円以下です。
  • 2 つの繰入は、名前が示す行き先が違う「財政融資資金へ繰入」は、特別会計の外の資金（財政融資資金）へのお金の移しです。「国債整理基金特別会計へ繰入」は、主要経費別の分類コードが国債費（20）で、国債の償還などのための別の特別会計への移しです。財投債の発行（歳入）はこのデータに無いので、繰入の財源は確かめられません。

FY2020 の補正で 3 回動き、FY2021 の当初は「途中の額」を前提にした

財政融資資金へ繰入の額を、補正の回ごとに並べました。FY2021 の予算書は、前年度予算額を 54.2兆円と書いています。これは FY2020 の第 2 次補正の後の額で、第 3 次補正で 40.7兆円に減る前の値です。

勘定ごとの全数値（兆円）

3 つの勘定の、当初・補正後・現額・支出済・翌年度繰越・不用を開く

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の特別会計の予算書（項・目）、補正予算書（回ごと）、決算書（項・目）。当初は FY2017〜FY2022 が各年度、FY2023・FY2024 も各年度、FY2025 は国会提出時、FY2026 は予算書の版です。FY2017〜FY2021 の当初は、提出時か成立後かを判定できていません。
  • nihon-no-yosan が抽出・構造化した CSV（項・目）を使いました。補正後は、補正予算書に載る項はその最後の回の改予定額、載らない項は当初の額です。決算の歳出予算額は、全年度・全項で、この補正後の額と円まで一致しました。
  • 決算の 2 つの式（歳出予算現額 = 歳出予算額 + 前年度繰越 + 予備費使用 + 予算総則による増額 + 流用 + 移替、歳出予算現額 = 支出済 + 翌年度繰越 + 不用）は、全年度・全項で円まで成り立ちました。勘定ごとの合計は、画面用のデータ（lifecycle）から足した値とも 1 円以内で一致しました。
  • 勘定の合計、割合、補正の回ごとの並べ方、文章の解釈は、この探索で計算・判断したものです。
  • 確かめられないこと: 歳入（財投債の発行、財政融資資金からの受け入れなど）はデータに無く、繰入の財源と、財政融資資金での使い道（貸付先）は分かりません。国債整理基金特別会計の側では、財投債の償還分を分けられません。「財政融資資金へ繰入」が財投債で調達したお金を資金へ移すものだという読みは、名前からの推測です。
  • 確かめられないこと: 政府が公表する財政投融資計画（財政融資の計画額など）とは別の数字で、照合していません。FY2021 に当初で 45兆円を組み、補正で 30兆円減らした理由も、このデータにはありません。
  • FY2025・FY2026 は決算がまだありません。FY2026 は補正もありません（基準データの時点）。

次に、聞かせてください

  • FY2021 の当初 45兆円と、補正後 15兆円・支出 10.1兆円の差を、どう受け取りましたか。予算の「上限」と「実際」の差として見ると、ほかの会計でも同じことが起きているか比べられます。
  • 国債整理基金特別会計へ繰入（FY2021 当初 26.6兆円）は、国債整理基金の側の債務償還費の山（FY2021・FY2022）と重なります。2 つの会計を並べて追いますか。
  • 投資勘定の産業投資支出は、毎年の不用の割合が高めです（例: FY2021 は現額 0.37兆円のうち不用 0.18兆円）。出資先の単位（目・RS の事業）まで降りますか。
