国から地方へ渡るお金は、10 年でどう変わったか

予算書の目には、経済性質別の分類コードが付いています。そのうち「対地方政府移転」（コード 80〜86）を、一般会計と特別会計で足しました。地方交付税は、一般会計から交付税特別会計を通って地方へ渡るので、特別会計の側で数えています。

増えた分の 4 割強は、地方交付税

    • 地方交付税 16.7兆円 → 20.2兆円（+3.6兆円）交付税特別会計から地方へ渡る額です。FY2023 の 17.0兆円から、3 年で +3.2兆円と、伸びが早まっています。
    • 子ども・子育ての給付は、特別会計を通るようになったFY2017 は、一般会計の「子どものための教育・保育給付費負担金」0.79兆円が、地方へ直接渡っていました。FY2018 にこの目は一般会計から無くなり、年金特別会計（子ども・子育て支援勘定）から地方へ渡る額が 1.52兆円 → 2.42兆円に増えています。FY2025 からは、子ども・子育て支援特別会計（4.4兆円）が受け持っています。
    • 地方譲与税 2.5兆円 → 3.2兆円FY2020 から「特別法人事業譲与税譲与金」（FY2026 は 2.60兆円）が加わりました。
    • 地方特例交付金は年で大きく動くFY2024 は 1.13兆円、FY2026 は 0.82兆円（うち「軽油引取税減収補填特例交付金」0.43兆円が FY2026 に新しく出た）。ほかの年は 0.1〜0.4兆円です。

    地方交付税の通り道

    一般会計は、地方交付税の財源を交付税特別会計へ繰り入れます。特別会計は、それを地方へ渡し、あわせて過去の借入金の返済などのために国債整理基金特別会計へ繰り入れます。

      • 国債整理基金への繰入は 32.7兆円 → 26.8兆円地方へ渡す地方交付税（20.2兆円）より大きい額です。この中に、借入金の元本・利子・借換えの分がどれだけあるかは、このデータでは分けられません（交付税特別会計の歳入が無いため）。
      • FY2025 は、一般会計からの繰入（18.9兆円）が、地方へ渡す地方交付税（18.3兆円）を上回ったほかの 9 年度は、地方へ渡す額の方が大きい年です（差は FY2017 で 1.2兆円）。理由はこのデータでは分かりません（未確認）。

      一般会計から直接渡るお金（国庫補助負担金など）

      目の名前ごとに、府省・項をまたいで足しました（こども家庭庁への移管をならすため）。「防災・安全社会資本整備交付金」は FY2022 に「防災・安全交付金」に名前が変わったので、まとめています。

      • 一番増えたのは、障害者自立支援給付費負担金（1.05兆円 → 1.81兆円）毎年増え続けています。障害児入所給付費等負担金も 0.18兆円 → 0.51兆円です。
      • 公共事業の交付金は減った社会資本整備総合交付金 0.89兆円 → 0.46兆円、防災・安全交付金 1.11兆円 → 0.85兆円。かわりに、道路更新防災等対策事業費補助（FY2020 から 0.23兆円前後）や下水道防災事業費補助のような、目的を絞った補助が増えています。
      • FY2026 の新顔給食費負担軽減交付金 0.16兆円。高等学校等就学支援金交付金は 0.40兆円 → 0.58兆円と、1 年で 0.18兆円増えています。
      • 「地方創生推進交付金」（FY2024 まで約 0.06兆円）は、FY2025 から無いFY2025 に「新しい地方経済・生活環境創生交付金」（0.14兆円）が出ています。後継かどうかは、このデータでは確かめていません（推測）。

      数えなかったもの: 医療・介護の保険への国の負担

      後期高齢者医療は広域連合、介護保険・国民健康保険は市町村などが運営しますが、予算書の経済性質別では「対地方政府移転」ではなく「他に分類されない国内経常移転」（コード 71）です。この LP は、分類コードどおりに、上の合計に入れていません。名前だけで地方向けと決めると、この額だけ合計が大きくなります。表は、一般会計の経済性質別 71 の目のうち、目名に「後期高齢者」「介護」「国民健康保険」を含む負担金・交付金・補助金です。全国健康保険協会・国民健康保険組合（運営するのが地方ではないもの）と、災害の臨時の補助金は除きました。「等」が付いた改称 3 件は、まとめています。

      この数字の作り方と、確かめられないこと

      • 財務省「予算書・決算書データベース」の予算書（目の表）の当初予算額と、目の経済性質別分類コード。コード 80〜86 の名前（対地方政府移転、経常支出、資本形成、現金による社会保障給付、社会扶助給付、経常補助金、その他）は、予算書のコード表のページから。FY2025 は国会提出時の版。FY2017〜FY2021 は、提出時か成立後かを判定できていません。
      • nihon-no-yosan が目の行を抽出・構造化したもの。コード 80〜86 の合計は、予算書の目の CSV を直接足した値と、全年度・一般会計と特別会計とも千円単位で一致しました。交付税特別会計の項の額も、項の CSV と一致しました。
      • 区分の分け方（交付税特別会計の項、子ども・子育て、その他）、目の名前ごとの合算、名前の変更 1 件のまとめ、FY2018 の付け替えの読み方、医療・介護の保険を合計に入れない判断は、この探索で決めたものです。
      • 一般会計から特別会計への繰入（コード 30「会計間重複」）は数えていないので、二重には数えていません。ただし、特別会計が自分の財源（税・借入など）から渡す分も含みます。財源の内訳は、歳入のデータが無いので分かりません。
      • 地方が受け取った額（決算）や、地方側の歳入とは照合していません。総務省・財務省が公表する「国から地方への財政移転」の額とも照合していません。名目の金額で、物価の調整はしていません。補正予算は含めていません。
