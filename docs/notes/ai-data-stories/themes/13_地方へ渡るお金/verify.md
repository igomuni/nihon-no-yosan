# テーマ C「国から地方へのお金」検算の記録（2026-11-03）

## 定義
- 「地方へ渡るお金」= 予算書の目の経済性質別分類コードが 80〜86（対地方政府移転とその内訳）の当初予算額（政府案）。一般会計と特別会計の両方。名前では判定しない。
- 一般会計 → 特別会計の繰入（コード 30「会計間重複」）は数えない。地方交付税は、交付税特別会計の目（コード 86）で数える。
- FY2025 は `2025_teishutsu`（国会提出時）。ほかは各年度の予算書。

## AI の判断（LP では .tag.ai）
- 区分: 交付税特会の項（地方交付税・譲与税・特例交付金と交通安全対策特別交付金）、子ども・子育て（年金特会の対地方から業務取扱費を除いた分 + 子ども・子育て支援特会）、一般会計、その他の特会。
- 目の名前ごとの合算（府省・項をまたぐ）。改称のまとめ: 防災・安全社会資本整備交付金 → 防災・安全交付金（FY2022、同じ項・同じコード 82）、医療・介護の保険の「等」付きの改称 3 件。
- FY2018 の付け替え: 一般会計の「子どものための教育・保育給付費負担金」0.79 兆円が FY2018 に無くなり、年金特会の対地方が +0.90 兆円。額の動きからの読み（同じものの確認はしていない）。3 回目の「子育て予算の引っ越し」の未確認「FY2018 の繰入の増加」の候補の説明になる。
- 医療・介護の保険の負担金を合計に入れない（分類コードに従う）。
