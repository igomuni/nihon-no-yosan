- 契約概要を NFKC で正規化し、`d1.py` の RULES を上から当て、最初に当たった種類。当たらなければ事業名で同じ順に当てた（調達のうち 1,059 件・5,082億円）。どれにも当たらなければ「その他」。
- 「その他」は 1.58兆円で一番大きい。その 78% は方式が「その他」の支払い（在日米軍関連の支払いなどと推測。未確認）。
- 「修理・整備」は、契約概要に修理・整備・保守・維持・改修・補修・点検などがある調達（航空機 837億円 / 調達 4,945億円）。
