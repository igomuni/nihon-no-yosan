補正は「補正後 − 当初」（目ごと）。FY2026 は補正第1号だけで、この 3 区分の目はありません。

  • 当初で毎年積むのは、科研費の基金学術研究助成基金補助金（科学研究費助成事業）は、10 年とも当初予算にあり、計 1.18兆円です。当初の基金の 8 割に当たります。
  • 補正で積む研究開発の基金革新的研究開発推進基金補助金（1.35兆円）、宇宙開発支援基金補助金（0.80兆円、FY2023〜）、創発的研究推進基金補助金（0.33兆円）など。どれも、ほぼ補正だけで積まれています。
  • FY2020 の保証の基金経営安定関連保証等基金補助金は、FY2020 の補正で 1.25兆円です。中小企業の資金繰りの保証に関わる基金と、名前から推測します。

    この数字の作り方と、確かめられないこと

    • 財務省「予算書・決算書データベース」の予算書（目の表）。一般会計の当初予算（FY2025 は国会提出時の版）と補正予算（補正後の額。年度に複数回あるときは、目が個別の行で載る最後の回）。
    • nihon-no-yosan が抽出・構造化した目のデータ。概算要求書にだけある目は除きました。
    • 判定の規則（目名）: 「特別会計へ繰入」「運営費交付金」「分担金」「拠出金」「給付費負担金」「事務局」「国際交流基金」「年金基金」を含むものは除く。そのうえで「基金」または「造成費補助金・交付金」を含む → 基金、「出資金」を含む → 出資金、「資金へ繰入」を含む → 資金への繰入。国債整理基金特別会計への繰入や、国際交流基金・年金基金のように組織名に「基金」が入るものは数えません。
    • 補正 = 補正後 − 当初（目ごと）。補正の表で「外N目」にまとめられ、個別の行が無い目は、補正の値なし（足していません）。この 3 区分で、そうした目は 118 件（補正の額は 0 と推測。確かめていない）。
    • 検算: 予算書の目の CSV を直接読み、同じ規則で当初と「全ての回の補正差引額の和」を足しました。10 年度・3 区分とも、上の値と一致しました（差は最大 0.001兆円で、丸めによる）。RS の当初予算の額とも一致します（上の節）。
    • 出資金は、基金とは性質が違います（政策金融機関・独立行政法人の資本）。この LP では、法人に積むお金として並べて示しています。
    • 未確認: 基金に積んだお金が、その後いつ・どれだけ使われたか（基金の残高・執行はこのデータに無い）。名前に基金が無い補助金のうち、基金に積まれた額。特別会計からの基金。決算の額との照合。政府が公表する基金の一覧との照合。
