# テーマ B「基金へのお金」検算の記録（2026-11-03）

## 判定の規則（目名。一般会計、FY2017〜FY2026、概算要求書にだけある目は除く）
1. 除く: 「特別会計へ繰入」「運営費交付金」「分担金」「拠出金」「給付費負担金」「事務局」「国際交流基金」「年金基金」を含む（国債整理基金特会への繰入、組織名の基金など）
2. 基金: 「基金」を含む、または「造成費補助金・交付金」を含む
3. 出資金: 「出資金」を含む
4. 資金への繰入: 「資金へ繰入」を含む
- 当初 = 政府案（目の budget）。補正 = 補正後 − 当初（目ごと。補正の行が無い目は値なし）。
