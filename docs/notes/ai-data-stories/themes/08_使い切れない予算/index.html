一般会計・決算 FY2017〜FY2024 · 翌年度繰越と不用

使い切れない予算は、どこで生まれ、どこへ行ったか

決算では、その年度に使えるお金（歳出予算現額）が、支出済・翌年度繰越・不用の 3 つに分かれます。繰越と不用が大きい項を探し、毎年続くものと、コロナ期に偏るものを分けました。繰越が翌年度にどうなったかは、事業のまとまりごとに入りと出を締めて追いました。

繰越の山は FY2020〜FY2022、不用の山は FY2022

繰越・毎年続く項繰越・1 年に偏る項繰越・その他不用・続く不用・偏る

「毎年続く」= 8 年のうち 6 年以上で繰越があり、1 つの年度に 8 年分の半分以上が集まっていない項（確定した対応で年度をたどった流れ）。「偏る」= 1 つの年度に半分以上が集まる項。区分はこのページで決めたもの。

繰越の大きい項

繰越の 8 年計は、年度末の残高を 8 年分足したもの。同じお金を 2 年続けて繰り越すと 2 回数えます（下の「繰越の行方」では、二重に数えない締め方をしています）。

不用の大きい項

予備費の項は、使った分が他の項へ移り、残った分が不用になる仕組みです。予備費の項の不用は「使わなかった予備費」です。

繰越の行方: 入りと出を締める

支出済翌年度繰越不用

各年度の棒は、その年度に使えるお金（現額）の分かれ方。入り = 歳出予算額 + 予備費使用 + 流用 + 移替（まとまりの中の移替は打ち消し合う）。締め = 入り + 期首の繰越 − 支出 − 不用 − 期末の繰越 で、5 つとも 0 円になりました。決算書は、支出済を「今年度の予算から」と「繰越分から」に分けていないので、繰越したお金そのものが使われたかは、期間で締めた結果でしか言えません。

内閣府の繰越率が高い理由

  • お金を持つ府省と、払う府省が違う新型コロナ対応の地方創生臨時交付金の項は、内閣府と総務省に同じ名前であります。内閣府の項は、FY2020〜FY2023 の 4 年とも支出済が 0 円で、毎年度、予備費使用などで受けたお金を総務省へ移し替え（FY2021 は −3.37兆円）、残りを翌年度へ繰り越していました。払っているのは総務省の項です。内閣府だけを見ると「繰越が 100%」に見えますが、2 つの項を合わせると、5 年で 18.3兆円が入り、15.1兆円（82%）が支出、3.3兆円（18%）が不用で、FY2024 末の残りは 0 円です。

次に、聞かせてください

  1. 公共事業の項（社会資本総合整備・河川・道路）は、毎年およそ 3 割を繰り越し、不用はごくわずかです（社会資本総合整備は 8 年で、入りの 94% を支出、不用は 0.6%）。これを「遅れ」と見るか「年度をまたぐ工事の普通の形」と見るか、どちらが気になりますか。
  2. コロナ期の交付金・給付金の不用（例: 協力要請推進交付金の不用 2.35兆円）は、目の単位でさらに分けられます。どの事業を深掘りしますか。
