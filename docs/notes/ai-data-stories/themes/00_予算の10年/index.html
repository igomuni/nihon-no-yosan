大きく動いた経費の 10 年

目盛りはそれぞれ違います。点線は FY2017 の水準。

見ておきたい 5 つの動き

  • 国債費 23.5兆円 → 31.3兆円（+7.8兆円）一番大きな増加です。FY2024 以降、毎年 1〜3兆円ずつ増えています。一般会計の国債費は、ほぼ全額が国債整理基金特別会計への繰入（目「普通国債等償還財源等国債整理基金特別会計へ繰入」23.0兆円 → 30.8兆円）なので、利払いと償還の内訳は、このデータの一般会計の側からは分けられません。
  • 防衛関係費 5.1兆円 → 9.0兆円（+3.9兆円）FY2023 だけ 10.2兆円に跳ねています。この年は目「防衛力強化のための資金へ繰入」3.38兆円があり、翌年は 0 です。使途別の物件費も 3.0兆円 → 6.7兆円と倍以上になり、そのうち防衛関係費の物件費が 1.9兆円 → 5.0兆円でした。装備品の購入・修理（例: 航空機修理費 0.43兆円（FY2022）→ 1.01兆円（FY2024））がここに入ります。
  • 少子化対策費 2.1兆円 → 3.5兆円（+1.4兆円）中身の器が大きく変わっています。FY2023 にこども家庭庁ができ、FY2025 から子ども・子育て支援特別会計への繰入（児童手当・教育保育給付など）に変わりました。名前の違う項が多いので、項を年度でたどるより、分類コードで見る方が全体をつかめます。
  • 社会資本総合整備事業費 2.0兆円 → 1.3兆円（−0.7兆円）減った経費で一番大きいものです。FY2019 の 2.2兆円をピークに減り続けています。同じ公共事業でも、道路整備（1.3 → 1.7兆円）や治山治水（0.8 → 1.0兆円）は増えています。
  • 予備費: コロナ期の「別枠」と、通常の予備費の倍増通常の予備費は 0.35兆円 → 1.0兆円。別に、FY2021〜FY2022 は新型コロナ等の予備費が各 5兆円、FY2023 は 4兆円とウクライナ情勢対応 1兆円、FY2024 は 1兆円がありました（FY2025 は 0、FY2026 は無し）。使途別の「その他」が FY2021〜FY2023 に 7兆円近くあるのは、このためです。

所管（府省）で見ると

  • こども家庭庁ができて、内閣府が 2兆円減ったように見えるFY2023 にこども家庭庁（4.0兆円）ができ、内閣府（外局を除く）は 3.6兆円 → 0.6兆円になりました。項の名前で見ると、こども家庭庁の最大の項「子ども・子育て支援年金特別会計へ繰入」2.5兆円は前年の内閣府に、母子家庭等対策費・保育対策費などは前年の厚生労働省にありました。残る約 1.2兆円（障害児支援等対策費・大学等修学支援費など）は、前年の同じ名前の項が無いか複数あり、どこから来たかをこのデータでは決められません。
  • 組織の付け替えをならすと内閣府（外局を除く）・こども家庭庁・厚生労働省を合わせると、33.3兆円 → 40.0兆円（+6.6兆円）です。社会保障と子ども・子育ての増加は、ここに集まっています。
  • 財務省 +7.9兆円の中身国債費（+7.8兆円）と予備費（+0.7兆円）です。FY2021〜FY2023 の山（30.5〜35.5兆円）は、新型コロナ等の予備費（各 4〜5兆円）と、FY2023 のウクライナ情勢対応の予備費です。FY2023 は、防衛関係費の「防衛力強化のための資金へ繰入」3.38兆円も、防衛省ではなく財務省の所管に入っています。
  • 減った府省は小さい経済産業省（0.98 → 0.87兆円、−0.11兆円。エネルギー対策特別会計への繰入が減った）、警察庁（−0.03兆円）、農林水産省（−0.02兆円）、環境省（−0.01兆円）。一般会計の当初予算で、はっきり減った府省はありません。

府省は、予算書の所管を分けたもの。内閣府の外局（こども家庭庁・デジタル庁・金融庁など）は、それぞれの府省として数えています（このサイトの画面と同じ数え方）。

減ったもの

一般会計全体が 25% 増える中で、主要経費別で 0.1兆円以上減ったのは 3 つだけでした。社会資本総合整備事業費（−0.69兆円）、恩給（0.29兆円 → 0.05兆円で −0.25兆円。分類コードが FY2022 に 4 つから 1 つにまとまったので、合算して比べました）、エネルギー対策費（−0.16兆円）です。項で見ると、東日本大震災の復興事業費の特別会計への繰入が 0.57兆円 → 0.07兆円に減っています。

名目の金額です。物価の変化は調整していません。物価で割り戻すと、増減の見え方は変わります。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の予算書（目の表）。一般会計の当初予算。FY2025 は国会提出時の版。FY2017〜FY2021 は、提出時か成立後かを判定できていません。
  • nihon-no-yosan が目の行を抽出・構造化し、分類コード（主要経費別・使途別）を付けたもの。目の合計は、各年度の項の合計と千円単位で一致することを確かめました。
  • 経費ごとの合計、増減、割合、「恩給」4 コードの合算、文章の解釈は、この探索で計算・判断したものです。政府の公式な集計（主要経費別の予算額の公表値）とは、作り方が違うので一致するとは限りません。照合していません。
  • 分類コードの名前は年度で変わるものがあります（例: 94 は「新型コロナウイルス感染症対策予備費」など 3 つの名前を持つ）。表の名前は最新の年度のものです。
  • 特別会計（社会保障・国債整理基金など、会計間の繰入で二重に数えるもの）は含めていません。補正予算・決算も含めていません。毎年の補正で、実際に使える額は当初より大きくなります。

次に、聞かせてください

  1. 一番意外だったのはどれですか。理由も聞かせてください。そこから掘り下げます。
  2. 国債費の増加は、金利の上昇によるものか、借金の残高によるものか。特別会計（国債整理基金）の側を調べると、利払いと償還を分けられるかもしれません。
