# テーマ 1「予算の一生: 当初予算から決算まで」の検算記録

対象: 一般会計、FY2017〜FY2024（決算がある年度）。金額は円（表示は兆円）。

## 使ったデータとスクリプト

- `apps/web/public/data/lifecycle/data.json.gz`（項の出来事。`lifecycleValues` で項目ごとの値にする）
- `apps/web/public/data/lifecycle/moku.json.gz`・`codes.json.gz`（目の決算の値と、主要経費別のコード・名前）
- `data/dataset/{reference-v0,mof-history-v0}/mof-archive/{年度}/kou-general-kessan.csv`（検算用。原本に近い決算の項の CSV）
- `s1.ts`: 年度ごとの合計と、項ごとの恒等式の確認
- `s2.ts`: 予備費の使用（府省別）と、府省別の 8 年合計
- `s3.ts`: 主要経費別（目の分類コード）の合計と、目の合計 = 項の合計の確認
- `s4.ts`: 決算の項の CSV を直接足して、s1 の合計と比べる
- `page-data.json`: LP に埋め込んだ値（億円に丸めたもの）

## 確かめたこと

| 確認 | 方法 | 結果 |
|---|---|---|
| 年度ごとの合計（歳出予算額・前年度繰越・現額・支出済・翌年度繰越・不用） | 画面用データの合計（s1）と、`kou-general-kessan.csv` を直接足した値（s4） | 8 年度 × 6 列すべて、円単位で差 0 |
| 現額 = 歳出予算額 + 前年度繰越 + 予備費使用 + 流用等 + 移替 | 決算のある全項（7,314 項）で計算 | 全項で一致（不一致 0） |
| 現額 = 支出済 + 翌年度繰越 + 不用 | 同上 | 全項で一致（不一致 0） |
| 翌年度繰越（y 年度）= 前年度繰越（y+1 年度） | 年度の合計で比較 | 7 組すべて円単位で一致 |
| 目の合計 = 項の合計（現額・支出済・繰越・不用） | s3 で目の値を足し、s1 と比較 | 差は浮動小数の丸め（0.001 千円未満）だけ |
| 予備費使用額の合計 | 年度ごとに足すと 0（予備費の項がマイナス、使った項がプラス） | 使った側（プラス）だけを足して、使用額とした。予備費の項のマイナスの合計と一致 |

## 主な数値

- 8 年度の合計: 当初予算 840.4兆円、補正による増減 +176.3兆円（決算の歳出予算額 1,016.7兆円 − 当初）、支出済 973.7兆円、不用 37.5兆円。
- FY2020: 当初 102.7兆円 → 歳出予算額 175.7兆円（+73.0兆円）→ 現額 182.3兆円 → 支出済 147.6兆円（81.0%）、翌年度繰越 30.8兆円、不用 3.9兆円。
- 支出済の割合: FY2017 94.5%、FY2020 81.0%、FY2022 81.9%、FY2024 89.4%。
- FY2022 の不用 11.3兆円（現額の 7.0%）。FY2017〜FY2019 は 1.4〜1.8兆円（1.4〜1.6%）。
- 予備費使用: FY2020 9.43兆円（厚生労働省 4.17・内閣府 3.41・経済産業省 1.64）、FY2022 7.61兆円。FY2022 のコロナ等予備費は 9.86兆円のうち 2.78兆円が不用。
- 繰越率（8 年合計、現額 1兆円以上の主要経費）: 災害復旧等 47.8%、文教施設 44.7%、公園水道廃棄物処理等 38.9%、社会資本総合整備 33.0%。
- 府省（8 年合計）: 内閣府は繰越率 33.3%・不用率 10.2%、国土交通省は繰越率 31.7%。

## 未確認・推測

- 「補正による増減」は、決算の歳出予算額 − 予算書の当初予算額で出した。補正予算書の補正額の合計と一致するかは比べていない（予算書と決算書で項の数が違う。FY2024 は 784 項と 978 項）。
- 当初予算の版（FY2017〜FY2021 は提出時か成立後か判定できていない）。
- 政府が公表する決算の概要の数字とは照合していない（外部検索をしていない）。
- 不用・繰越の理由（見積もりとの差、事業の遅れなど）は、このデータからは分からない。LP では「無駄」と言わないようにした。
- 内閣府の繰越率・不用率が高い理由（どの項か）は、まだ項の単位で見ていない。
- 特別会計は扱っていない。
