一般会計・決算 FY2017 → FY2024 · 予算決定後移替増△減額

予算を持つ府省と、お金を払う府省

決算書には、予算が決まったあとで別の府省へ移した額（予算決定後の移し替え）が、目ごとに書かれています。8 年分の 208 の目を、出し手と受け手の組に分けました。

8 年の移し替えの計（受け手の側の合計）
うち、コロナ・物価高騰の地方創生臨時交付金（内閣府 → 総務省）
組織の新設・移管にともなう分（デジタル庁・こども家庭庁・水道）
2.35兆円協力要請推進交付金のうち、内閣府の項に残ったまま不用になった額（FY2022）

移し替えは、ほぼ 1 種類の交付金

臨時交付金を除いた残りは、右の目盛り（億円）で別に描いています。

出し手と受け手の組

同じ目名（無ければ同じ項名）で、出し手の減額と受け手の増額が円まで一致する組を、対応とみなしました。一致しない分は「対応不明」です。

  • 内閣府 → 総務省 10.85兆円（FY2020〜FY2024 の 5 年続く）新型コロナ対応・物価高騰対応の地方創生臨時交付金です。予算書（当初・補正）では内閣府の項に計上され、支出は総務省の同じ名前の項から出ています（3 回目の「交付金の行方」と同じ流れ）。
  • 組織ができた年・移った年だけの組FY2021 のデジタル庁（内閣官房・内閣府・総務省・経済産業省から、情報システムの経費 0.01兆円）、FY2023 のこども家庭庁（厚生労働省・文部科学省・内閣官房から 0.35兆円）、FY2024 の厚生労働省 → 国土交通省（水道施設の整備・耐震化・災害復旧 0.06兆円）。どれも 1 年だけです。目名からは、組織の新設・所管の移動にともなうものと読めます。
  • 毎年続く小さな配分内閣府の科学技術・イノベーション推進事務局の「科学技術イノベーション創造推進費」は、FY2018 と FY2021〜FY2024 に、経済産業省・国土交通省・厚生労働省・農林水産省などへ移されています（FY2021 の 9億円から FY2024 の 50億円）。沖縄教育振興事業費（内閣府 → 文部科学省、FY2022〜FY2024）、地方創生整備推進交付金（内閣府 → 国土交通省・農林水産省・環境省、FY2023〜FY2024）も続いています。

どの項で、どの年に

受け手の側の項名ごとの、年度別の額（億円）です。色の濃さは額の大きさ（行ごとではなく全体で共通）。

FY2019 は、移し替えが 1 件もありません。デジタル庁の情報システムや公共事業のように、予算の段階でまとめて計上して各府省で使う形は、決算の移し替えにはほとんど出ていません（デジタル庁は発足した FY2021 だけ）。予算の段階で各府省へ計上されているためと推測しますが、確かめていません。

協力要請推進交付金 2.91兆円の経過

FY2021 の補正予算で内閣府に 1.50兆円が付き、同じ項の臨時交付金の目から 1.41兆円が流用されて、現額は 2.91兆円になりました。FY2021 は支出 0 円で全額を繰り越し、FY2022 に 0.56兆円だけ総務省へ移し替えて支出しました。残りの 2.35兆円は、内閣府の項に残ったまま、支出されずに不用になっています。

不用になった理由は、決算書のデータにはありません。

府省別の集計に、どう効くか

予算書（当初・補正）の所管で数えると、この交付金は内閣府のお金です。決算で実際に払ったのは総務省です。府省別に「いくら使ったか」を数えるとき、予算書の所管で数えるか、決算の支出の所管で数えるかで、内閣府と総務省の額が年 1〜3兆円ずつ動きます。

移替前 = 歳出予算額 + 前年度繰越 + 予備費使用 + 流用等。現額 = 移替前 + 移替。兆円。府省は予算書の所管（内閣府の外局の庁・委員会は、それぞれの府省として数える）。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の決算書（一般会計、目の表と項の表）。列「予算決定後移替増△減額」。FY2017〜FY2024。
  • nihon-no-yosan が抽出・構造化した CSV（moku-general-kessan.csv・kou-general-kessan.csv）。
  • 出し手と受け手の対応づけは、同じ年度の同じ目名（無ければ同じ項名）で、減額と増額の合計が 0 円になり、出し手か受け手の一方が 1 つに決まるものだけです。決まらなかったのは FY2021 の「情報処理業務庁費」61.8億円（出し手 4・受け手 2）で、「対応不明」としました。
  • 区分（臨時交付金・組織の新設・移管・配分）は、項名と年度・府省の組からの判断です。決算書に区分は書かれていません。
  • 検算: 移し替えの合計は、どの年度も 0 円でした。目の合計は項の表と、項ごとに円まで一致しました。対応づけと対応不明を府省ごとに足した純額は、項の表の府省別の純額と一致しました。移し替えのある 208 の目すべてで、決算の 2 つの恒等式が成り立ちました。
  • 確かめられないこと: 移し替えの手続きと理由、予算の段階での一括計上と配分（予算書の各府省への計上の内訳）、移し替えた額がどの財源（当初・補正・繰越）の分か、特別会計の移し替え、FY2025 以降。
