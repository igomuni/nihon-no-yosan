国の人件費は、10年でどれだけ増えたか

予算全体ほどは増えていない

増えた分の半分は防衛省

  • 防衛省の比重は 4 割強のまま
  • 外務省は現地の職員の給与が増えた外務省は 0.103 → 0.156兆円（+0.053兆円）。目「現地補助員給与」が 0.014 → 0.029兆円と倍になりました。
  • 新しくできた組織デジタル庁の人件費は、FY2021 の 30億円から FY2026 の 140億円になりました。こども家庭庁は FY2026 で 50億円です。どちらも、前の組織から移った分を含みます（どこから移ったかは、このデータでは分けていません）。

給与明細で見ると

人件費の目（給与の費目）ごとの増減です。基本給より諸手当の伸びが大きく、退職手当は減っています。

目の名前は、予算書のままです。自衛官の給与も「職員基本給」「職員諸手当」の目に入っています（防衛省の内訳は下の表）。

FY2026 は 1 年で 0.17兆円増えた

特別会計の人件費は小さい

一般会計から特別会計への繰入は、使途別では「他会計へ繰入」に分類され、人件費には入りません。そのため、2 つを足しても二重には数えていません。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の予算書・決算書（目の表）。当初予算は政府案。FY2025 は国会提出時の版。FY2017〜FY2021 は、提出時か成立後かを判定できていません。
  • nihon-no-yosan が目の行を抽出・構造化し、分類コードを付けたもの。人件費は、目の使途別分類コードが「1」の行です（一般会計は 5 つ目、特別会計は 4 つ目のコード）。
  • 年度・府省・目ごとの合計、増減、割合、文章の解釈は、この探索で計算したものです。予算書の目の CSV を直接読んで足した合計とも、全年度で千円まで一致しました。決算は、目の CSV で「現額 = 歳出予算額 + 前年度繰越 + 予備費使用 + 流用等 + 移替」「現額 = 支出済 + 翌年度繰越 + 不用」が、全年度で円まで成り立つことを確かめました。
  • 人数のデータは無いので、一人当たりの給与は分かりません。給与改定・定員の増減・年齢構成のどれが効いたかは、このデータからは分かりません。
  • 委託費・補助金の中で払われる人件費や、独立行政法人・地方公共団体の人件費は入っていません。名目の金額で、物価の調整はしていません。
  • 当初予算と、成立した予算（決算の「歳出予算額」）の差は、補正予算などによるものと考えられますが、目ごとの補正の記録とは照合していません。
