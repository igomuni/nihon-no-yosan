# テーマ D「人件費の 10 年」検算の記録（2026-11-03）

対象: 使途別分類コード「1」（人件費）の目。一般会計は 5 つ目、特別会計は 4 つ目のコード（`codesOfMoku`）。当初予算 = 予算書の目の当初の額（政府案。FY2025 は `2025_teishutsu`）。決算 = 決算書の目（FY2017〜FY2024、一般会計）。

## 主要な数値と検算

| 数値 | 値 | 検算 |
|---|---|---|
| 一般会計の人件費 FY2017 / FY2026 | 4,389,898,290 / 4,884,082,682 千円 | `moku.json.gz` の集計（p1.ts）と、予算書の目の CSV を直接読んで使途別 1 を足した値（v1.py）が、FY2017〜FY2026 の全年度で千円まで一致（差 0、p2.ts） |
| 特別会計の人件費 FY2017 / FY2026 | 194,775,883 / 201,628,793 千円 | p1.ts と v1.py が一致（0.195 / 0.202 兆円） |
| 一般会計に占める割合 | 4.50% → 3.99%（最低 FY2023 3.91%） | 分母は目の当初の額の合計（先の PoC で項の合計と千円まで一致を確認済み） |
| 防衛省の人件費 | 1.857 → 2.109 兆円（増加 0.494 兆円の 51%） | 府省別の合計（p1.ts）。府省は `lifecycleGroupsOf`（内閣府の外局は別の府省） |

| 決算（一般会計） | 不用 506〜751 億円/年（現額の 1.15〜1.71%） | 決算書の目の CSV を直接読んだ値（v2.py）と、`moku.json.gz` の決算の値（p1.ts）が一致（例: FY2024 不用 65,433,682,496 円 = 0.065 兆円）。v2.py で、使途別 1 の目について「現額 = 歳出予算額 + 前年度繰越 + 予備費使用 + 流用等 + 移替」「現額 = 支出済 + 翌年度繰越 + 不用」の差が全年度 0 円 |

## スクリプト

- p1.ts: 目のデータから、会計・府省・目名・特別会計名・年度別に集計（p1.json）
- p2.ts: CSV 直接との照合、防衛省の目、デジタル庁、繰越の上位、割合、府省別の不用
- v1.py: 予算書・決算書の目の CSV を直接読む検算（当初・決算）
- v2.py: 決算書の目の、現額の内訳と 2 つの恒等式（v2.json）
- build.ts: LP に埋め込むデータ（data.json。億円）
- page.py: LP（index.html と preview.html）を組み立てる
- stubtest.mjs: スクリプトの実行確認
