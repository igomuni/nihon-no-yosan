年金特別会計・決算 FY2017〜FY2024（決算がある 8 年度）

年金の予算は、見積もりと実績がどれだけ離れているか

基礎年金給付費: 見積もりは毎年増え、差も毎年広がった

  • 当初予算（見積もり）
  • 支出済（実績）
  • 差（不用）

基礎年金勘定の目「基礎年金給付費」。補正予算はなく、当初予算 = 補正後 = 歳出予算現額です（翌年度繰越も 0）。

勘定ごとの不用

    FY2023 から、基礎年金勘定に入れるお金も減らした

    • 一般会計 → 年金特会（基礎年金）
    • 厚生年金勘定 → 基礎年金勘定
    • 国民年金勘定 → 基礎年金勘定
    • 基礎年金給付費の不用（線）
    • FY2022 までは、入れるお金は見積もりどおり3 つの繰入は、FY2017〜FY2022 は当初予算とほぼ同じ額が支出されました（不用は FY2021 の計 0.03兆円だけ）。基礎年金給付費の側だけに、不用が積み上がっていました。
    • FY2023・FY2024 は、入れる側にも不用
    • 見積もりが大きい理由は、データに無い受給者の数や年金額の改定の見込みは、予算書・決算書の目の表には書かれていません。繰入の側を減らした手続きも、このデータからは分かりません。入れる側の不用（FY2024 は 5.52兆円）が、給付費の不用（4.56兆円）より大きい理由も未確認です。

    主な給付の、見積もりと実績

    8 年の不用が大きい目。各年度は「当初予算 / 支出済」（兆円）。

    • 厚生年金の保険給付費は、毎年 0.6〜0.8兆円の差で安定
    • 国民年金給付費は、見積もりも実績も毎年減っている

    全数値の表（兆円）

    勘定ごとの当初・補正後・現額・支出済・繰越・不用を開く

    この数字の作り方と、確かめられないこと

    • 財務省「予算書・決算書データベース」の予算書（目の表、当初予算）と決算書（目の表）。特別会計「年金」の 6 つの勘定。
    • nihon-no-yosan が抽出・構造化した CSV（mof-archive の moku-special.csv・moku-special-kessan.csv、一般会計は moku-general*.csv）。当初予算と決算を、勘定・項名・目名で結びました。補正後は、決算書の「歳出予算額」です。
    • 差・割合・合計、「見積もり」「実績」という呼び方、文章の解釈は、この探索で計算・判断したものです。不用（使われずに残った額）の良し悪しは評価していません。
    • 決算の 2 つの恒等式（現額 = 歳出予算額 + 前年度繰越 + 予備費使用 + 予算総則の増額 + 流用 + 移替、現額 = 支出済 + 翌年度繰越 + 不用）は、全部の目・年度で円まで成り立ちました。
    • 勘定の間の繰入（厚生年金勘定・国民年金勘定 → 基礎年金勘定）は、出す側と受ける側の両方の勘定で数えています。勘定を足した合計は、二重に数えた額を含みます。
    • 歳入（保険料・積立金からの受入・一般会計からの受入）はデータに無いので、使われなかったお金がどこに残ったかは分かりません。
    • 予備費の目は、予算書と決算書で目名が違う年度があり（「(予備費)」と「目未定」）、目の単位では結べないものがあります。勘定の合計には影響しません。
    • 名目の金額です。政府の公表値とは照合していません。FY2025 以降の決算はまだありません。

    次に、聞かせてください

    1. 見積もりと実績の差は、どの年度から気になりますか。差が毎年広がる形と、FY2023 に繰入の側を減らし始めた形の、どちらを掘りますか。
    2. 概算要求（FY2023〜FY2027）の基礎年金給付費と、当初予算・実績を並べると、見積もりはどの段階で決まっているかが見えるかもしれません。
    3. 一般会計の「基礎年金年金特別会計へ繰入」の FY2023 以降の不用（1.45・1.84兆円）は、一般会計全体の不用のどれくらいを占めるか、調べますか。
