国債費の 7.8兆円増、その半分は利払いの見込み

一般会計の国債費は、当初予算で 23.5兆円から 31.3兆円になりました。予算書の事項の名前で分けると、増えた 7.8兆円のうち 3.9兆円が利払い、4.3兆円が定率による償還です。利払いの予算は、FY2024 から急に増えています。一方、実際に払った利子（FY2024 までの決算）は、ほぼ横ばいです。

国債費を、事項の名前で 4 つに分ける

償還（定率繰入）償還（その他）利払い諸費・事務・その他
  • 定率による償還: 12.9兆円 → 17.2兆円（+4.3兆円）事項「定率による公債等償還財源の国債整理基金特別会計へ繰入れに必要な経費」。毎年、着実に増えています。
  • 利払い: 9.1兆円 → 13.0兆円（+3.9兆円）事項名に「利子」を含む 3 つ（公債利子等・年金特例公債利子・旧道路公団の借入金利子）の合計。FY2022 の 8.2兆円まで減り、FY2024 から 9.7 → 10.5 → 13.0兆円と増えました。
  • その他の償還: 1.5兆円 → 0.9兆円（−0.6兆円）年金特例公債・減税特例公債・旧道路公団の借入金などの償還財源。減税特例公債の償還（FY2017・FY2018 に各 0.26兆円）は、FY2019 以降の予算書にありません。

分け方: 事項名に「利子」→ 利払い、「定率による」→ 償還（定率繰入）、「償還財源」「整理収入」→ 償還（その他）、「諸費」「事務取扱い」→ 諸費・事務。FY2026 の「割引国債の発行価格差減額」0.13兆円は、その他に入れています。各年度の合計は、項の国債費と千円単位で一致します。

利払いの予算と、実際に払った利子

国債整理基金特別会計の目「利子及割引料」（国債整理支出）を、当初・補正後・決算で並べました。この特会は、一般会計の分だけでなく、財政投融資特会などが負担する国債の利子もまとめて払います。

当初予算補正後決算（支出済）
  • 当初予算より、毎年 1.9〜2.6兆円少なく払っているFY2017〜FY2024 の当初予算は 9.8〜11.5兆円、実際に払ったのは 7.9〜8.9兆円でした。毎年、補正で 0.9〜1.7兆円減らし、それでも 0.76〜0.98兆円が不用になっています。
  • FY2026 の当初予算は 16.5兆円FY2024 の 11.5兆円から 2 年で 5兆円増えました。実際に払った額は FY2024 の 8.9兆円までしか分からず、FY2025・FY2026 の決算はまだありません。予算の増加が、どこまで実際の利払いの増加になるかは、このデータでは確かめられません。

補正予算で、毎年同じことが起きている

一般会計の国債費の補正を、事項ごとに見ました。ほぼ毎年、利払いを 1兆円前後減らし、前の年度の決算の剰余金を国債整理基金に入れています。

利払いの減額決算上の剰余金の繰入その他の償還

FY2026 は第1号の補正だけで、国債費の事項の補正はありません。FY2019・FY2020 は剰余金の繰入がありません。

国債整理基金のお金は、どこから来ているか

国債整理基金特別会計の歳出（当初）は 196.6兆円（FY2017）、224.8兆円（FY2026）です。ほかの会計からの繰入は、両年とも 88兆円ほどで、残りの 109兆円（FY2017）と 137兆円（FY2026）は、繰入以外の財源です。

  • 歳出の 9 割は債務償還費目「債務償還費」は 180.9兆円（FY2017）、232.1兆円（FY2021）、204.4兆円（FY2026）。FY2021・FY2022 に大きく膨らんでいます。
  • 繰入では足りない分は、このデータに無いこのデータは歳出だけで、特会の歳入（借換債の発行による収入など）を含みません。繰入で足りない 109〜137兆円は、借換債で賄っていると考えられます（推測）。ここでは確かめられません。
  • 交付税特会からの繰入は減っている交付税及び譲与税配付金特別会計からの繰入は 32.7兆円 → 26.8兆円。一般会計からの繰入（国債費）は 23.5兆円 → 31.3兆円で、FY2026 に初めて交付税特会を上回りました。

一般会計の国債費と、特会の歳出は、同じお金を二度数えています。足し合わせないでください。

  • nihon-no-yosan が抽出・構造化したもの。一般会計の国債費の事項の合計は、各年度の項の額と千円単位で一致。特会の目の値は、元の CSV（FY2017・FY2020・FY2024 の決算、FY2017・FY2024・FY2026 の当初）を直接足した値と一致しました。
  • 「償還」「利払い」の区分は、事項名の語（「利子」「定率による」「償還財源」など）でこのページが決めたものです。財務省の公表する債務償還費・利払費の内訳とは照合していません。
  • 特会の「利子及割引料」は、一般会計の分以外（財政投融資特会などが負担する分）も含みます。一般会計の利払いの予算と、同じ範囲ではありません。

  • 名目の金額です。金利・国債残高は、このデータにありません。利払いの予算が増えた理由（金利の見込みか、残高か）は、ここでは分けられません。
