## 分類の根拠（AI の判断）
- 事項名の語で分けた: 「利子」→ 利払い、「決算上の剰余金」→ 剰余金の繰入、「償還及び発行に関する諸費」「事務取扱い」→ 諸費・事務、「定率による」→ 償還（定率繰入）、「償還財源」「整理収入」→ 償還（その他）、残り（割引国債の発行価格差減額）→ その他。事項名の一覧は d4.json。
- 特会の「債務償還費」「利子及割引料」は、目名そのまま。

- FY2017〜FY2021 の当初予算の版（提出時か成立後か）。

## スクリプト
- d1.ts: 特会の目、他会計からの繰入 → d1.json
- d2.ts: 一般会計の国債費・特会の項の当初・補正後・決算 → d2.json
- d3.py: 元の CSV での検算
- d4.py: 一般会計の国債費の事項の区分 → d4.json
- d5.py: 補正の事項の区分 → d5.json
- build.py: data.json から index.html・preview.html を作る
- stubtest.mjs: スクリプトの動作確認
- data.json は、d1/d2/d4/d5 の JSON を親のシェルで組み合わせて作った（スクリプトのファイルは残していない）。
