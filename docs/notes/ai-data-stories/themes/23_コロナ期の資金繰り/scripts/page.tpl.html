政策金融機関への出資、信用保証と利子補給、持続化給付金・家賃支援給付金を、一般会計の目の単位で足しました。入りは FY2020〜FY2022 の予算（前年度繰越・予備費・流用を含む）、出は同じ 3 年の支出・不用です。

    この数字の作り方と、確かめられないこと

    • 財務省「予算書・決算書データベース」の予算書（目の当初・補正の表、補正は回ごと）と決算書（目の表）。一般会計の FY2019〜FY2024 と、財政投融資特別会計の項。
    • nihon-no-yosan が抽出・構造化した CSV（mof-archive の moku-general*.csv、kou-special*.csv）を使いました。
    • 対象の目は、目名で選びました（8 種類）: 日本政策金融公庫出資金（財務・経産・厚労・農水）、危機対応円滑化業務出資金、商工組合中央金庫出資金、経営安定関連保証等基金補助金、中小企業再生支援利子補給補助金、持続化給付金、家賃支援給付金、事業再構築促進補助金（参考。資金繰りではなく事業転換の補助なので、合計に入れない）。名前に出てこない資金繰り支援（自治体の制度融資への補助など）は数えていません。
    • 入り = FY2020 の前年度繰越 + FY2020〜FY2022 の歳出予算額・予備費使用額・流用等・移替の和。出 = 同じ 3 年の支出済・不用と、FY2022 末の翌年度繰越。目ごとに、入りと出は円まで一致しました（締め 0 円）。年度ごとの支出の棒は FY2019〜FY2024 で、FY2023 以降の公庫出資は平時の額です。
    • 一般会計 → 財政投融資特別会計 → 政策金融機関のような通り道の二重計上を避けるため、一般会計の目で数え、財政融資資金への繰入は別の層として合計に入れていません。一般会計から財投特会の投資勘定への繰入（FY2020 補正 0.2兆円）と、投資勘定の産業投資は、コロナ対応に限らないので扱っていません。
    • 未確認: 出資・保証・利子補給を受けた機関の側での使われ方（貸付額、保証額）。危機対応円滑化業務出資金と商工中金出資金が不用になった理由。持続化給付金の FY2021 の補正 2.49兆円の中身（目名は同じ）。財政融資資金の貸付先。政府の公表値との照合。行政事業レビュー（2025 年度版）は FY2021 以降の事業で、2022 年度までに終わった給付金の事業は入っていない可能性があり、照合していません。
