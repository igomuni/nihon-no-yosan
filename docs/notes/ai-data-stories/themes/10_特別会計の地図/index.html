どの特別会計が大きく、どこが増えたか

棒は FY2026 の政府案（兆円）。右の数字は FY2017 からの増減。カーソルを当てると年度ごとの値が出ます。

  • 国債整理基金が全体の半分（224.8兆円）国債の償還と利払いの会計です。FY2017 の 196.6兆円から +28.2兆円。
  • 年金 +13.4兆円、子ども・子育て支援が新設（FY2025、5.8兆円）年金特別会計の 102.9兆円のうち 26.3兆円は、勘定の間の繰入（基礎年金勘定への繰入など）です。これを除くと、66.9兆円 → 76.7兆円（+9.8兆円）です。
  • 減ったのは、東日本大震災復興（2.7 → 0.6兆円）と交付税及び譲与税配付金（52.1 → 51.1兆円）交付税特会の地方交付税交付金そのものは 16.7兆円 → 20.2兆円に増えています。減ったのは、国債整理基金への繰入（32.7 → 26.8兆円）です。

国債整理基金の支出は、目の単位で「債務償還費」と「利子及割引料」に分かれています。一般会計の国債費（繰入の 1 本）では見えなかった内訳です。

  • 利子は 10.9兆円 → 16.6兆円（+5.7兆円）目「利子及割引料」の、国債整理支出・復興債整理支出・脱炭素成長型経済構造移行債整理支出の 3 項の計です（国債整理支出だけでは 10.91兆円 → 16.46兆円）。FY2020〜FY2023 は 10兆円前後で横ばいでした。FY2024 から 11.6、12.9、16.6兆円と増えています。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の予算書（項・目の表）。一般会計と特別会計の当初予算（政府案）。FY2025 は国会提出時の版。FY2017〜FY2021 は、提出時か成立後かを判定できていません。
  • nihon-no-yosan が項・目の行を抽出・構造化したもの。特別会計の目の合計は、全年度で項の合計と一致しました。
  • 繰入の見つけ方: 目の名前に「繰入」を含み、「〇〇特別会計」「一般会計」「〇〇勘定」へと読めるものを、会計の間の繰入として除きました。「財政融資資金へ繰入」「防衛力強化のための資金へ繰入」「育児休業給付資金へ繰入」など、資金への繰入は除いていません（FY2026 は計 13.2兆円）。
  • 「試算純計」は、単純合計から名前で見つけた繰入を引いただけの値です。国債整理基金の借り換えの分、名前に「繰入」の無い会計間の受け渡し、歳入の側は扱っていません。政府が公表する特別会計の歳出純計とは、作り方が違い、照合していません。
  • 特別会計は、補正予算・決算を含めていません。会計ごとに数え、所管（府省）では分けていません（複数の府省が所管する会計があるため）。
