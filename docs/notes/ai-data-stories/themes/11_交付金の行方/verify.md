## 表示
- ブラウザは使っていない（規則）。`stub.mjs` で DOM の代用を作ってスクリプトを最後まで動かし、属性に NaN・undefined が無いこと、SVG の座標（x・y・幅・高さ）が viewBox の内側にあることを確かめた（問題 0）。文字の幅は計算していない（右端の値ラベル「14.80兆円」は x ≈ 614 から、viewBox 幅 680）。
- 流れの図の縦軸の最大値は、データの最大（FY2021 の 12.56兆円）からきりのよい値に切り上げて計算（固定値にしない）。
