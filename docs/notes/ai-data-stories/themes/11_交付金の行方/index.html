地方創生臨時交付金は、どこを通って、どこで使われたか

新型コロナ対応と物価高騰対応の臨時交付金を、予算から決算まで追いました。お金は毎年、内閣府に入り、総務省へ移され、総務省から支出されています。内閣府の項からの支出は、5 年間で 0 円です。

年度から年度へ、繰越で流れる

各年度の左の棒が「使えるお金」（前年度からの繰越・補正予算・予備費）、右の棒が「その行き先」（支出・不用・翌年度への繰越）。紫の帯が、翌年度へ持ち越した額です。2 つの項（内閣府・総務省）を合わせると、内閣府から総務省への移し替えは相殺され、入りと出は毎年円まで一致します。

棒にカーソルを当てると、内訳が出ます。どちらの系統も、当初予算は 0 円（コロナは FY2020、物価高騰は FY2023 に項が無い）で、入りはすべて補正予算と予備費です。

持つのは内閣府、払うのは総務省

  • 予算書では内閣府、決算書では 2 つの府省に分かれる予算書（補正予算）では、補正の額の全部が内閣府の項に載っています。決算書では、同じ額が内閣府と総務省の「歳出予算額」に分かれていて、2 つの和は予算書の補正後の額と、6 つの年度・項すべてで円まで一致しました（例: FY2020 は 4.5兆円 = 内閣府 1.12兆円 + 総務省 3.38兆円）。分かれ方の手続きは、このデータには書かれていません。
  • 予備費は、毎回内閣府へ予備費の使用（コロナ 6.28兆円、物価高騰 1.13兆円）は、すべて内閣府の項に入っています。その年度のうちに一部が総務省へ移され（予算決定後の移替）、残りは翌年度へ繰り越され、翌年度にまた総務省へ移されます。
  • 内閣府の項に残ったまま使われなかった額内閣府の項の不用は、FY2022 の 2.58兆円と FY2023 の 0.44兆円です。FY2022 の不用のうち 2.35兆円は「協力要請推進交付金」で、前年度から繰り越した 2.91兆円のうち 0.56兆円だけが総務省へ移されました。

交付金の種類ごとの締め

目（交付金の種類）で分けると、使われ方がはっきり違います。協力要請推進交付金は、入りの 8 割が使われずに残りました。

  • 支出
  • 不用
  • FY2025 へ繰越

入り = 補正予算 + 予備費 + 流用。FY2021 に、地方創生臨時交付金の目から協力要請推進交付金の目へ 1.41兆円の流用があります。

行政事業レビューの事業とつなぐ

行政事業レビュー（RS、2025 年度版）には、2 つの交付金が 1 つずつの事業として載っています。RS の「補正予算・前年度からの繰越し・予備費等・執行額・翌年度への繰越し」は、決算の 2 つの項の和と、どの年度も 30 万円未満の差で一致しました（RS の 2021〜2022 年度は移行データで、百万円単位の丸めがある）。

  • RS だけに見える FY2025物価高騰対応の事業は、FY2025 に第 1 次補正予算 2.04兆円と前年度からの繰越 1.23兆円などで、歳出予算現額が 3.37兆円です。FY2025 の決算は、まだこのデータにありません。予算書でも、FY2025 の補正後 2.04兆円、FY2026 の補正後 0.10兆円が同じ項に載っています。
  • 予算書の項へのつなぎRS の 2-2（予算種別・歳出予算項目）の行を直接見ると、項と目が書かれているのは、物価高騰対応の FY2024・FY2025 の第 1 次補正予算の行だけで、どちらも内閣府の「物価高騰対応地方創生推進費」です。繰越・予備費の行と、コロナ対応の全部の行は、項が空欄です。総務省の項は、どの行にも出てきません。コロナ対応の事業は、名前と額の一致でしか照らせません。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の決算書（一般会計の項・目、FY2020〜FY2024）と予算書（補正後）。行政事業レビュー見える化サイト（2025 年度版）の 2-1 サマリ・2-2 予算種別・歳出予算項目。
  • nihon-no-yosan が抽出・構造化した CSV と画面用データ。決算の値は円単位、予算書の値は千円単位を円にしたもの。
  • 2 系統・2 府省の合算、入りと出の締め、交付金の種類ごとの合計、府省の役割の読み取りは、この探索で計算・判断したものです。
  • 確かめたこと: 決算の 2 つの恒等式（現額 = 歳出予算額 + 前年度繰越 + 予備費 + 流用 + 移替、現額 = 支出 + 翌年度繰越 + 不用）が全 35 行で成り立つ。目の合計 = 項の値。年度間の繰越の受け渡しが円まで一致。移替は 2 府省で相殺して 0。予算書の補正後 = 決算の歳出予算額（2 府省の和）。RS の額と決算の額の一致（差は 30 万円未満）。前の回（予備費の行方・使い切れない予算）のコロナ対応の締め（入り 18.33・支出 15.06・不用 3.27兆円）と一致。
  • 未確認: 予算書で内閣府にある額が、決算書で総務省の歳出予算額になる手続き。支出した額が、どの年度の予算（補正・予備費）から出たか（決算書は財源ごとに分けていない）。交付先の自治体ごとの額と、自治体での使い道（このデータに無い）。FY2025 以降の決算。
  • 名目の金額です。良し悪しの評価はしていません。
