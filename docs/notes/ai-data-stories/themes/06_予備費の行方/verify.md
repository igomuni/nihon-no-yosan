# テーマ A「予備費の行方」検算の記録（2026-11-03）

対象: 一般会計の決算（FY2017〜FY2024）。FY2017〜FY2022 は `data/dataset/mof-history-v0/mof-archive/{年}/`、FY2023・FY2024 は `data/dataset/reference-v0/mof-archive/{年}/` の `moku-general-kessan.csv`・`kou-general-kessan.csv`。当初予算額は `apps/web/public/data/lifecycle/data.json.gz`（予算書の政府案）。

## スクリプト
- `r1.ts`: 目の決算の「予備費使用額」を年度ごとに集計。予備費の項（項名が「予備費」で終わる）と、使った目（プラス）を、府省（`lifecycleGroupsOf`）・主要経費別・項に分ける。予備費の項の当初額は、予算書の同じ所管・項コードの項から取る（項名は補正で変わることがあるため）。→ `r1.json`
- `r2.ts`: 検算。項の決算 CSV の予備費使用額で、プラス・マイナスの合計を足し直す。予備費の項の恒等式を確かめる。
- `r3.ts`: 予備費だけで現額ができた目（歳出予算現額 = 予備費使用額）の、支出・繰越・不用。→ `r3.json`
- `r4.ts`: LP 用のデータ（億円）。→ `page-data.json`
- `build.py`: LP の HTML（`index.html` は発行用の断片、`preview.html` はそのまま開ける版）。`stub.mjs`: DOM の代用で LP のスクリプトを動かし、NaN・undefined が出ないことを確かめる。

## 検算の結果
| 確かめたこと | 方法 | 結果 |
|---|---|---|
| 使用額（プラスの合計）= 予備費の項（マイナスの合計） | 目の CSV で、8 年度それぞれ | 円まで一致 |
| 目の集計と項の集計 | 項の CSV の予備費使用額で足し直し | プラス・マイナスとも、8 年度とも円まで一致 |
| 予備費以外の項のマイナス | 項の CSV | 0 件（マイナスは予備費の項だけ） |
| 予備費の項: 歳出予算額 − 使用 + 流用 + 移替 = 現額 = 支出 + 繰越 + 不用 | 全年度・全予備費の項 | 成立（流用・移替・支出・繰越はすべて 0） |
| 決算の歳出予算額 = 補正後の額 | 補正の値が取れる項（FY2017〜FY2021、FY2024 など） | 一致。項名の変わった FY2022・FY2023 の項は、補正の値を名前で取れないので、決算の歳出予算額を「計上（補正後）」とした |
| テーマ 1 との整合 | FY2020 9.426兆円、FY2022 7.607兆円 | 一致 |
| 予備費だけの目の恒等式（支出 + 繰越 + 不用 = 予備費使用額） | 8 年度 | 成立 |
| 地方創生臨時交付金（FY2020・FY2022、内閣府） | 目の決算の行を直接読む | FY2020: 歳出予算額 1.118兆 + 予備費 3.379兆 − 移替 1.629兆 = 現額 2.868兆、支出 0、繰越 2.868兆。総務省の同じ目に移替 +1.629兆。FY2022: 予備費 2.400兆、現額 1.800兆、支出 0、繰越 1.677兆、不用 0.123兆 |

## 主な数値
- 8 年: 計上（補正後）33.66兆円、使用 25.97兆円（77%）、不用 7.69兆円。FY2020〜FY2022 の使用 22.10兆円（85%）。
- 年度の使用: FY2017 0.087、FY2018 0.195、FY2019 0.467、FY2020 9.426、FY2021 5.067、FY2022 7.607、FY2023 1.439、FY2024 1.685兆円。
- 府省（8 年計）: 厚生労働省 9.50、内閣府 9.42、経済産業省 5.08兆円（3 府省で 92%）。
- 項（8 年計）: 感染症対策費 6.81、新型コロナウイルス感染症対応地方創生推進費 6.28、燃料安定供給対策費 1.92兆円。
- ウクライナ情勢経済緊急対応予備費: FY2022 計上 1.0兆、FY2023 計上 0.5兆（当初 1.0 を補正で減額）。使用は 2 年とも 0 円。
- 通常の予備費: 計上 0.30兆（FY2017）→ 1.00兆（FY2024）。使用率 29%（FY2017）〜93%（FY2019）。
- 予備費だけで現額ができた目: 632 件（目 × 年度）のうち 86 件、0.97兆円（使用額の 3.7%）。
