どこへ使われたか

予備費を受け取った目の分類コード（主要経費別）で分けています。府省は予算書の所管（内閣府の外局は、それぞれの府省）。

使った先で、そのお金は使われたか

  • 地方創生臨時交付金は、内閣府から総務省へ移し替えて配るFY2020 に予備費から 3.38兆円を受けた「新型コロナウイルス感染症対応地方創生臨時交付金」は、内閣府の側では支出 0 円でした。予算決定後の移替で 1.63兆円が総務省へ移り、もとの予算 1.12兆円と合わせて残った 2.87兆円は、全額が翌年度へ繰り越されています。FY2022 も予備費 2.40兆円を受けましたが、内閣府のこの目は支出 0 円で、移替のあと 1.68兆円を繰り越し、0.12兆円が不用でした（目全体の値）。

目の現額・支出・繰越・不用は、その目全体の値です。予備費の分だけの値ではありません。

この数字の作り方と、確かめられないこと

  • 財務省「予算書・決算書データベース」の決算（一般会計の目・項）の「予備費使用額」。予備費の項はマイナス、使った目はプラスで載っています。当初予算額は予算書（政府案）から。
  • nihon-no-yosan が抽出・構造化した CSV（FY2017〜FY2022 は過去年度のデータセット、FY2023・FY2024 は基準データ）。
  • 年度ごとに、使った側（プラス）を足した額と、予備費の項（マイナス）の額は、8 年とも円まで一致しました。項の決算の CSV で足し直しても同じでした。予備費の項では、歳出予算額 − 使用額 = 現額 = 不用額 が成り立っています（支出・繰越は 0）。テーマ「予算の一生」の FY2020 9.43兆円・FY2022 7.61兆円とも一致します。
  • 1 つの年度に予備費の項が 2 つ以上あるとき（FY2020〜FY2023）、どの目が、どの予備費から出たかは、このデータでは分けられません。府省別・経費別の金額は、その年度の予備費全体からの使用額です。
  • 目の現額には、当初予算・補正・前年度繰越・移替も入っているので、予備費の分だけが、支出されたか・繰り越されたか・不用になったかは分けられません（予備費だけで財源ができた目を除く）。
  • 予備費の使用の理由・閣議決定の日付は、このデータにありません。補正の回ごとの額は、項ごとに最後の回の額です。特別会計の予備費は扱っていません。
  • 名目額。政府が公表する予備費の使用実績とは照合していません。
