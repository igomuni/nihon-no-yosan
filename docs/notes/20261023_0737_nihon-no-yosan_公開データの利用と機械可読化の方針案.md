# nihon-no-yosan — 公開データの利用と機械可読化に関する方針案

作成日時: 2026-10-23 07:37 JST  
状態: **議論の整理・未確定ドラフト**。正式な採用・実装指示・既存PRの変更を意味しない。

## 1. 目的

`nihon-no-yosan` は、各公的機関が一般に公開している予算・決算・行政事業レビュー等の情報について、人間が資料を閲覧して確認できる**事実情報の機械可読性、検索性、比較可能性、出典追跡性**を高めることを目的とする。

PDFのテキスト抽出、正規表現による項・事項・目・金額等の識別、CSVへの再構成、複数の原本の突合と可視化は、この目的のためのデータ構造化である。原本の著作物を代替配布したり、原本の意味・数値・表現を恣意的に書き換えたりすることを目的としない。

**ただし、目的が機械可読化であるだけで、あらゆる複製・再配布が適法になると主張するものではない。** 利用行為と公開対象物の実体によって評価する。

## 2. 技術的・研究的な不変条件

- 原本で確認できない文字・数値・符号を推測しない。
- 空欄とゼロを区別する。差額・検算結果等の導出値は原本値とは別に管理し、導出値を原本値として補完しない。
- 原本の文字列と、検索・突合用の正規化キーは区別する。
- 取得元URL、対象文書、年度・版、ページ・行、原本・基準データのSHA-256等を可能な範囲で保持する。
- 取得原本、内部の基準CSV、構築データ、外部公開物の役割と境界を区別する。
- 利用者が原本に遡って検証できるようにする。不明・未確認・曖昧な事象はその状態で記録する。

## 3. 著作権・利用条件に関する判断の整理

次の論点を混同しない。

1. **著作物性**：数値・コード・単純な科目名などの事実情報と、創作的な説明文・図画・選択や配列に創作性のある編集物とは区別する。事実情報は一般に著作権の保護対象となりにくいが、CSV全体について一律に断定しない。
2. **利用許諾**：PDL1.0、CC BY等の明示的ライセンスが対象コンテンツに適用される場合は、その範囲と条件に従う。規約の不明確さと、事実情報の利用禁止とは同義ではない。
3. **公開する行為**：内部解析、事実データの抽出、構築データの公開、原本PDFや長い説明文の再配布を分けて考える。
4. **確認可能性**：AIが公式サイトへアクセスできない、あるいは個別規約が見つからないことは、データが利用不可であることの証明ではない。反対に、禁止文言が見つからないことだけで無条件に利用許諾が成立するわけでもない。
5. **権限と真正性**：ユーザー申告、書面の回答、公開された公式規約は証拠の種類が異なる。AIに本人確認書類などを不用意に提出させることを確認手段の前提にしない。

## 4. 判断・記録の基本姿勢

**法的な絶対保証をGO条件にしない。** 代わりに、対象物・利用行為・確認できた一次情報・解釈・残る不確実性を明示し、具体的な問題に応じて対処する。

データソースまたは公開データセットごとに、次を記録する。

- 提供主体、原本URL、確認した利用規約URL、確認日
- データの種類と公開対象列・範囲（数値、科目名、原文説明、画像等）
- 適用ライセンスまたはその確認状況
- 著作権の保護対象外と判断する場合は、その具体的な根拠と対象範囲
- 第三者権利・個別例外・転載禁止表示などの確認結果
- 事実（確認済み）／解釈／未確認事項の区別
- 公開時の出典・加工主体・加工内容の表示

公開規約の確認が難しい場合も、根拠と不確実性を残して判断する。**AIによる検証不能を一律のSTOP理由としない**一方、創作的な表現や原本資料の複製について具体的な権利上の懸念が確認された場合は対象を切り分けて検討する。

## 5. 現在の適用例と未確定事項

- **財務省の予算書・決算書アーカイブ**：財務省の公式利用規約と、別ドメインのアーカイブCSV・XMLへの適用範囲を区別して記録する。未確認の適用範囲を「不許可」とは表現しない。
- **RSシステムの一括CSV**：行政改革関係の公式利用規約と、`rssystem.go.jp` の一括CSV固有の条件を区別する。AIからの確認が難しいこと自体を利用不可の根拠としない。
- **国会・裁判所関連の概算要求資料**：サイト上の著作物の転載・改変に関する一般的規定と、予算額・コード・科目名などの事実データの利用を分けて評価する。PDF・画像・説明文を公開することと、機械可読化した事実データを公開することを区別する。

`nihon-no-yosan` PR #4 は既にユーザー判断によりマージ済み。本書はその判断を差し戻すものではなく、今後の公開方針を定式化するためのドラフトである。

## 6. 今後の方針確定時に決めること

- 内部基準CSVと外部公開データの契約を同一にするか、分離するか。
- 各データセットの根拠・確認状態・出典表示をmanifestへどう記録するか。
- 具体的な権利上の問題が見つかった場合の訂正・公開停止・差替え手順。
- 誰が最終的な公開判断を承認し、その判断記録をどこに置くか。
