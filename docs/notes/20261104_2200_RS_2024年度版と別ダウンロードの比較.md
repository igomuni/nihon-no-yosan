状態: 作業メモ。比べた事実と、そこから言えないことを分けて書く。
入力（3 つ。いずれも読み取りだけ。zip は作業用の別の場所に展開した）:
- **2024:** 旧リポジトリ `marumie-rssystem/data/download/rssystem.go.jp/download-csv/2024/` の zip（ファイルの更新日 2026-09-19）。15 ファイル。
- **9月版:** 同 `download-csv/2025/` の zip（同 2026-09-19）。15 ファイル。
- **4月版:** このリポジトリの `data/download/rs/2025/`（旧リポジトリの `data/year_2025` と 3 ファイルのハッシュが一致。更新日は 2026-04-14）。これまでの洗い出しは、すべてこれを使った。

## 1. 同じ「2025 年度版」が 2 通りある

「9月版」と「4月版」は、ファイル名は同じ（`*_RS_2025_*`）だが、中身が違う。

| 点 | 9月版（2024 と同じ形） | 4月版（これまでの洗い出しの対象） |
|---|---|---|
| 先頭の BOM | あり | なし |
| 見出しのかっこ・記号 | 全角（`（合計）`、`／`、`－`） | 半角（`(合計)`、`/`、`ー`） |
| NFKC で変わるセル | 718,873 / 10,738,201（6.7%）。全角かっこ 363,598、全角数字、全角スペース、`％` `／` `：` | **0** / 10,694,080 |
| 改行を含むセル | 8,921（ほぼ 3-2 の列） | 0 |
| 3-2 の列数 | 25 | 23（「派生元ー活動指標／成果指標」「派生先ー活動指標／成果指標」が無い） |
| 5-1 の行数 | 193,912 | 194,738 |
| 3-1 の行数 | 128,516 | 128,476 |
| 文章の例 | 「令和6年度ウェブ会議システム~新任管理者…」 | 「2024年度ウェブ会議システム新任管理者…」（元号が西暦に、`~` が無い） |
| 空白の例 | 「トラスト担当 政府認証基盤(GPKI)班」 | 「トラスト担当政府認証基盤(GPKI)班」（空白が無い） |

- 行の順序を問わず（NFKC で揃えて）比べても、5-2・5-3・5-4・6-1 でさえ、同じ行は 68〜93% にとどまる（5-2 89%、5-3 68%、5-4 84%、6-1 93%）。1-2・1-3・2-2・5-1 などは、さらに低い（5-1 は 1%）。元号→西暦、空白・記号の除去が、広い範囲の文章に及んでいる。
- 事業 ID の集合は同じ（どちらも 5,794 事業）。5-1 だけ、17 事業で、行が「4月版」にしか無い（旧の同じ事業の行と一致しない）。
- **どちらが元の配布物かは確かめていない。** 考えられるのは、(a) RS のサイトが、4 月（4月版）と 9 月（9月版）で、出力の仕様や中身を変えた。(b) 4月版は、旧リポジトリで取り込む途中に、NFKC・元号の西暦化・空白の除去・列の削除などの加工を受けた。(c) 各府省が、データを更新した。
- 旧リポジトリの記録（プロンプトログ 2026-04-30）に、`data/download/RS_2025` の zip を `data/year_2025` に展開した旨はあるが、加工の有無は書かれていない。

**この比較で直すこと:**
- 手がかりのメモ D 節の「RS のシステムか CSV の出力で NFKC 相当の変換がされている」は、**根拠が足りない**。9 月のダウンロード（2024・9月版）は正規化されていない。正規化されているのは「4月版」だけ。
- 同じく D 節の「改行を含むセルは 0」は、「4月版」の性質。9 月のダウンロードには、3-2 の列に改行がある（8,309〜8,921 セル）。改行・箇条書きの入力形式は、9 月のダウンロードで見られる。
- 公開しているデータセット `rs-v0`（1-2・2-1・2-2）と `rs-spend-v0`（5-1〜5-4）は、「4月版」から作った。`manifest.json` の「手を加えずに入れた」は、このリポジトリで手を加えていないという意味で、サイトの配布物そのままかは未確認。

## 2. 2024 年度版と 2025 年度版（旧）の比較（どちらも 9 月のダウンロード）

形は同じ（見出し 15 ファイルすべて一致、BOM あり、非正規化）。

| 点 | 2024 | 9月版 |
|---|---|---|
| 予算事業 ID の数 | 5,664 | 5,794 |
| 共通の事業 | 5,231 | |
| 年度にだけある事業 | 433 | 563 |
| 事業名が変わった事業（共通の中で） | 263 | |
| 府省庁が変わった事業（共通の中で） | 0 | |
| 5-x の名前のある行のうち法人番号が 13 桁の数字 | 167,916 | 170,391 |
| 検査用数字エラー | 26 組 / 61 行 | 53 組 / 147 行 |
| 番号なし（空、9 だけ）の行 | 42,267 | 40,059 |
| 5-2 の府省庁が 1-2 と違う事業 | 415 | 416 |
| ゼロ幅スペースのセル | 72 | 245 |
| 私用領域の文字のセル | 5 | 5 |
| 真偽値の表記 | 5-1・5-2 は TRUE/FALSE、5-4 は t/f | 同じ |

- **検査用数字エラーは、年度を越えて引き継がれていない。** 2024 の 26 組と、2025 の 53 組は、重なりが 0。2024 の 26 組のうち 13 組は、2025 に同じ名前で出てくる（法人番号が直った、または別の番号）。残り 13 組は 2025 に同じ名前がない。
- **構造上の不一致は、年度が変わっても残る。** 5-2 の府省庁（外局を親の府省で出す）が 415→416 事業、真偽値の表記の不統一は同じ、私用領域の文字は 5 セル。システム側の仕様の可能性が高い（推測）。
- 事業名は、共通の 5,231 事業のうち 263 事業で変わった。名前を事業のキーにはできない（予算事業 ID を使う）。
- 9月版の検査用数字エラー（53 組・147 行）は、「4月版」の結果（53 組・147 行）と同じ。

## 3. サイトの現行の配布物との照合（2026-11-04）

`https://rssystem.go.jp/download-csv/2025` の ZIP 15 本（URL は `https://rssystem.go.jp/files/2025/rs/<ファイル名>.zip`）を、ブラウザのメモリ上で取得し（ファイルとしては保存していない）、サイズと SHA-256 を、手元の 9月版の ZIP と比べた。

| 比べたもの | 結果 |
|---|---|
| ZIP のサイズ | 15 本すべて一致 |
| ZIP の SHA-256（先頭 12 桁） | 15 本すべて一致 |
| ZIP の中の CSV の SHA-256 | 15 本すべて、9月版の CSV と一致 |
| 4月版（このリポジトリの `data/download/rs/2025/`）の CSV | 15 本とも、サイトの CSV と**一致しない**（行数・列・文字が違う、第 1 節） |

- **9月版は、サイトの現行の配布物と同一。** 4月版は、サイトの現行の配布物と違う。
- サイトのページに「データは 2026年1月19日時点のもの」とある。サーバーの `Last-Modified` は 15 本とも 2026-10-29 23:37:09 GMT（配信側の更新日で、データの時点ではない）。
- つまり、4月版は、(a) サイトが以前配っていた版、または (b) 取り込みの途中で加工された版。どちらかは、まだ確かめていない。

## 4. 1 本化の案

- **基準は、サイトの ZIP（= 9月版）にする。** 配布物そのままで、サイトの SHA-256 と照合できる（出どころが説明できる）。正規化（NFKC、空白、元号など）は、このリポジトリの処理として別に行い、規則を記録する。
- 切り替えると、これまでの 4月版から作ったものが変わる。画面の RS タブ（`rs/jigyo.json.gz`）、公開済みの `rs-v0`・`rs-spend-v0`、AI Data Stories の 5 本。変わる範囲は、先に差分で測る。
- 公開済みの `rs-v0`・`rs-spend-v0` の出し直しは、切り替えを決めてから（タグを変える）。

## 限界

- 4月版と9月版の関係は、上のとおり未確認。ユーザーが、旧リポジトリでの取り込み方を覚えていれば、確かめられる。
- 2024 と 9月版の比較は、5-x の法人番号と 1-2 の事業名・府省庁だけ。説明文・金額の年度間の変化は見ていない。
- 2024 年度版の列の洗い出し（分類、値の性質）は、していない（見出しは 9月版と同じ）。
